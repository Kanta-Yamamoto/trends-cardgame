# 設計 v5：闇堕ち（オワコンから）

10月18日にオーナーと決めた。ルールは [rules.md](rules.md) の「闇堕ち」。最初は「推し枠」の形で入れたが、同じ日に下の「v5.1」の形に改めた。

## なぜ変えるか

- 4〜5ターン目に先に盤面をそろえた側（先攻・横に並べるデッキ）が押し切る試合が多い
- 後から出す強いアイコンは、そのターンに相手のアイコンに触れられず、盤面を返せない（コントロールがアグロに負ける）
- 遊び手が自分で流れを変えられる場面が少ない
- せっかくの闇堕ちが「たまたま引いた★4〜5が倒されたら勝手に裏返る」だけで、判断に関わっていなかった

## 決めたこと

| 項目 | 内容 |
|---|---|
| 推し | ★5は推し枠専用。デッキ（25枚）の横に1枚置き、話題力を払えばいつでも出せる |
| 推しのコスト | 4〜6。属性の戦い方で決める（炎上は早く、神・癒しは遅めで盤面除去が大きい）。推し枠にいる間、自分のアイコンが倒されるたびに1下がる（最低3） |
| 推しの役割 | 出たときに盤面除去などの効果（例：体力2以下を一掃、相手全体を眠らせる） |
| 闇堕ち | 推しが倒されたら、次の自分のターンから1回だけ、オワコンから闇堕ちの姿で出せる。タダ。出たターンから相手のアイコンを攻撃でき、「闇堕ちしたとき」の効果がある |
| 演出 | 闇堕ちのとき、両方の画面に全画面の演出（元の絵にひび → 砕けて闇の絵 → 「闇堕ち」の文字） |
| やめたこと | 倒されたら自動で裏返る闇堕ち。★4〜5に広く闇堕ちを配ること |

## v5.1：推し枠をやめ、闇堕ちはオワコンからいつでも

オーナーが遊んでみての判断：

- 推し枠に★5が固定されていると、そこまでのドローや手札の組み立てが意味を持たなくなる → ★5は山札に戻し、手札から普通に出す
- 闇堕ちは「強制的に場に戻る」のではなく、闇堕ちを持つカードがオワコンに行って以降、**好きなタイミング（倒されたそのターンも）でコストなしで**出せる
- 狙い：闇堕ちの姿の「闇堕ちしたとき」で除去 → 倒されたらもう一度出てきて除去、という返しの手を作る
- 闇堕ちの姿がそのまま殴れると強すぎるので、**出たターンは攻撃できない**とした（業火のカグラの速攻も外した）。→ 10月19日に見直し：戻ってきたターンから相手のアイコンにだけ攻撃できる（凸）。経緯は history.md
- 1枚につき1回（`darkSpent` で数える）。TL浄化で戻しても、もう一度は闇堕ちしない

## 検討して外した案（今後の候補）

- **進化（シャドバ型）**：強化＋出たターンに相手のアイコンを攻撃できる。シャドバそのものになるのでやめた
- **バズ**：名前が草の「バズり動画」などと被る
- **トレンド（フィールド）**：試合前に選ぶ、1試合1回の大技（単体除去・全体除去・固有キャラ）。推しと役割が重なるので外した。場に残る「トレンド」カードとして、後で使う候補
- **闇堕ちにライフの条件（10以下など）**：条件を重ねると闇堕ちがほぼ起きない（測定で 6〜8% の試合）ので外した

## 確かめること

- 推しを出したターン（目安：平均5ターン目まで）、闇堕ちが起きた試合の割合（目安：7〜8割）、デッキ別の勝率
- 初回の総当たり（各組み合わせ30戦）：推しを出した 88%（平均3〜5ターン目）、闇堕ちした 45%、デッキの勝率 24〜66%。闇堕ちの割合とデッキの偏りは、マージ後に調整する
