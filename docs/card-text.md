# 効果文の書き方

カードの効果文（`effect`・`dark.effect`）の決まり。言葉は [glossary.md](glossary.md) の呼び名だけを使う。決まりの多くはテスト（`packages/cards/src/glossary.test.ts`）で確かめていて、守っていない文は CI を通らない。

## 考え方（10月24日）

- **カードには「何が起きるか」だけを書く**。キーワード・状態・仕組みの説明はカードに書かず、語を押すと開く解説の小窓（`apps/web/src/help`）に任せる
- **新しい仕組みには、必ず名前を付ける**。効果で付くものは「〇〇状態」、能力は「キーワード」として用語集と解説の小窓に登録してから、カードに名前だけ書く（例：「相手のキャラクター1体を眠り状態にする」。眠りの中身は小窓）
- 同じ動きは、どのカードでも同じ文で書く。カードゲーム好きが、ほかのゲームの知識で読めるようにする

## カードに載せる文字（10月24日）

オーナー：「カードを成り立たせる上で不要な『文章』『言葉』は全て削除対象」「これがあると楽しいだろうな、みたいな余計な文言は全て不要であり、カードを成り立たせる説明文以外は不要」「レアリティの高さも関係ありません」

- 載せてよいのは **名前・コスト・攻撃力・体力・★・種類（キャラクター・呪文・トークン）・属性・種族・効果文・闇堕ちの札** と、数字の見出し（攻撃・体力）だけ
- 載せない：肩書き・フレーバー・通し番号・英語の名前・飾りの文字（「LIVE」「依頼状」「SETLIST」「査読済み」「報酬：話題ひとつ」「もぐもぐ」など）・効果が無いときの「効果なし」。★5 の専用デザインでも同じ。飾りは絵と形と色で出す
- 属性の印は、属性名の頭の字（炎・推・水・自・神。ニュートラルは ニ）。種族の印（配・ア・有・動・ミ）と同じ形。属性名と並べて出す所では印を出さない（「炎 炎」のように重ねない）
- カードのデータ（`CardDef`）にも、肩書き・フレーバー・通し番号の項目は無い（データベースの列だけ残し、空にしている）
- テスト（`apps/web/src/cards/cardText.test.tsx`）で、全カードのカード面（闇堕ちの姿も）を描き、上の文字以外が無いことを確かめる

## 文の並び

1 枚の効果文は、次の順に並べる。どれも文の終わりに「。」を付ける。

1. **キーワード**：ガード。速攻。突進。連撃。注目。コンボ。（この順。1 つずつ「。」で区切る）
2. **手札にある間**：手札にある間、〜コスト-N。
3. **場にいる間ずっと**：自分の場のほかの〇〇1体につき攻撃力+1。
4. **きっかけ**：場に出たとき → 突進で攻撃したとき → 自分のターンの終わりに → 相手のターンの始めに → 破壊されたとき（闇堕ちの姿は「闇堕ちしたとき」）

## 文の型

| 動き | 書き方 |
|---|---|
| 引く | カードを N 枚引く／さらにカードを 1 枚引く |
| ダメージ | 相手のキャラクター1体に N ダメージ／相手のキャラクターすべてに N ダメージ／相手のプレイヤーに N ダメージ |
| 破壊 | 相手のキャラクター1体を破壊する／体力が N 以下の相手のキャラクターすべてを破壊する |
| 回復 | 自分のライフを N 回復する／自分のキャラクターすべてと自分のライフを N 回復する |
| 強化 | 自分のキャラクター1体に攻撃力+N・体力+N／このターン攻撃力+N |
| 弱体 | 相手のキャラクター1体の攻撃力-N |
| 状態 | 相手のキャラクター1体を眠り状態にする／晒し状態にする／沈黙状態にする |
| キーワードを付ける | 自分のキャラクター1体に突進を付ける |
| トークン | 草を N 体出す／自分の空いている枠すべてに草を出す／トークンとして、このキャラクターのコピーを1体出す |
| 戻す | 相手のキャラクター1体を持ち主の手札に戻す |
| 奪う | 攻撃力が N 以下の相手のキャラクター1体を奪う |
| 探す | 山札から〇〇種族のカードを1枚探して手札に加える。なければカードを1枚引く |
| プレイヤーに付ける効果 | 相手のプレイヤーに「〜」効果を付与する（「〜」の中は、付けられた側から見た「自分の」で書く） |

### 対象の書き方

- **誰のか**を必ず書く：自分の〜／相手の〜／自分のほかの〜
- **選ぶ対象**：相手のキャラクター1体（遊ぶ人が選ぶ）
- **自動で決まる対象**：攻撃力がいちばん高い相手のキャラクター1体／コストがいちばん高い相手のキャラクター1体
- **条件で絞ってから自動で決まる対象**：攻撃力が N 以下の相手のキャラクターのうち、攻撃力がいちばん高い1体
- **ランダム**：ランダムな自分のほかのキャラクター1体
- 数は「1体」「N枚」を必ず付ける

## 使わない書き方

| 使わない | 代わりに |
|---|---|
| 括弧（ ）での説明・補足 | 語の説明は解説の小窓へ。条件・例外は文にする（「センターに出したときは、左右に2体出す。」） |
| 状態の中身を書く（「眠らせる（次のターン攻撃できない）」） | 「眠り状態にする」 |
| 状態を動詞で書く（眠らせる・晒す・訂正する） | 「〇〇状態にする」 |
| 用語集にない呼び名（アイコン・投稿・オワコン・話題力・マスター・界隈・倒す・墓場・ドロー・召喚・登場時） | 用語集の呼び名 |
| +N/+N | 攻撃力+N・体力+N（画面の数字の表示には使ってよい） |
| 全角の数字 | 半角の数字 |
| フレーバー（セリフ・雰囲気の文）・肩書き | 書かない（カードのデータにも項目が無い。[working-agreement.md](working-agreement.md)） |

## 新しい語を足すとき

1. [glossary.md](glossary.md) に呼び名・意味・コードの名前を足す（王道のゲームでの言い方も調べて書く）
2. 解説の小窓（`apps/web/src/help/help.ts`）に、押したときの説明を足す
3. カードには名前だけを書く

## テストで確かめていること

- 使わない呼び名が無い（カード名・肩書きの中は除く）
- 括弧・全角の数字・「N/N」が無い
- 文の終わりが「。」
- キーワードが、決まった順に先頭にある
- 「〇〇状態」は用語集に登録した状態だけ
- 解説の小窓の文も、使わない呼び名を使っていない。押せる語と使わない呼び名は、すべて glossary.md に載っている
- 画面の文字（`apps/web/src`・`packages/game-core/src`・`apps/api/src` の文字列。コメントは除く）にも、使わない呼び名が無い（各パッケージの `terms.test.ts`）
