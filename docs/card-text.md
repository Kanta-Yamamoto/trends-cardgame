# 効果文の書き方

カードの効果文（`effect`・`dark.effect`）の決まり。言葉は [glossary.md](glossary.md) の呼び名だけを使う。

**効果文は、効果データ（`effects`）から組み立てる**（10月24日）。組み立てる関数は `packages/cards/src/text.ts` の `effectText`・`darkEffectText` で、この文書の決まりはその関数に書いてある。`cards.json` の `effect` は、関数で作った文と 1 字も違わないことをテスト（`packages/cards/src/text.test.ts`）で確かめていて、違うと CI を通らない。用語の決まりは `glossary.test.ts` で確かめる。

決まりの元にした調べ（7 つの代表的なカードゲームの日本語の効果文、1,992 枚）は [research/card-text/](research/card-text/README.md)。

## 考え方（10月24日）

- **カードには「何が起きるか」だけを書く**。キーワード・状態・仕組みの説明はカードに書かず、語を押すと開く解説の小窓（`apps/web/src/help`）に任せる
- **説明は、語を押した先の小窓にだけ置く**（10月24日。オーナー：「効果とか言われるものの説明は、必ず省略が可能で、必ずモーダルに置くことができる」「例えば疾走だったら、その定義を、文言を押した先のモーダルに貼る。シャドウバースはそうなっている」）。カードの拡大・対戦中の説明の帯にも、キーワード・状態・闇堕ちの説明を並べない。出すのは語だけ（効果文に無いキーワード・今の状態は、押せる札にする）。テスト（`apps/web/src/game/CardZoom.test.tsx`）で、拡大の画面に解説の小窓の文が無いことを確かめる
- **新しい仕組みには、必ず名前を付ける**。効果で付くものは「〇〇状態」、能力は「キーワード」として用語集と解説の小窓に登録してから、カードに名前だけ書く（例：「相手のキャラクター1体を眠り状態にする」。眠りの中身は小窓）
- 同じ動きは、どのカードでも同じ文で書く。カードゲーム好きが、ほかのゲームの知識で読めるようにする
- 書き方に迷ったら、代表的なカードゲームの多数派に寄せる。多数派が割れるときは、短く、スマホで読みやすいほう（ハースストーン・Shadowverse の型）を選ぶ

## 新しいカードの効果文の作り方

1. `effects` に効果データを書く（`types.ts` の `CardEffect`）
2. `effect` は空のまま `pnpm --filter @trends/cards test` を回す。`text.test.ts` が落ちて、作った文（`text`）を出すので、それを `effect` に写す
3. 作った文で言えない動きを足すときは、`text.ts` に型を足してから使う（この文書の「文の型」にも足す）。カードの `effect` だけを手で直さない

## カードに載せる文字（10月24日）

オーナー：「カードを成り立たせる上で不要な『文章』『言葉』は全て削除対象」「これがあると楽しいだろうな、みたいな余計な文言は全て不要であり、カードを成り立たせる説明文以外は不要」「レアリティの高さも関係ありません」

- 載せてよいのは **名前・コスト・攻撃力・体力・★・種類（キャラクター・呪文・トークン）・属性・界隈・効果文・闇堕ちの札** と、数字の見出し（攻撃・体力）だけ
- 載せない：肩書き・フレーバー・通し番号・英語の名前・飾りの文字（「LIVE」「依頼状」「SETLIST」「査読済み」「報酬：話題ひとつ」「もぐもぐ」など）・効果が無いときの「効果なし」。★5 の専用デザインでも同じ。飾りは絵と形と色で出す
- 属性の印は、属性名の頭の字（炎・推・水・自・神。ニュートラルは ニ）。界隈の印（配・ア・有・動・ミ）と同じ形。属性名と並べて出す所では印を出さない（「炎 炎」のように重ねない）
- カードのデータ（`CardDef`）にも、肩書き・フレーバー・通し番号の項目は無い（データベースの列だけ残し、空にしている）
- テスト（`apps/web/src/cards/cardText.test.tsx`）で、全カードのカード面（闇堕ちの姿も）を描き、上の文字以外が無いことを確かめる
- 効果文をカード面に載せ続けるかは、11/1 の公開のあと、カード作りに入る最初に決め直す（10月28日。[working-agreement.md](working-agreement.md)「カード面に効果文を載せ続けるか」）

## 文の並び

1 枚の効果文は、次の順に並べる。どれも文の終わりに「。」を付ける。

1. **キーワード**：ガード。速攻。突進。連撃。注目。便乗。コンボ。（この順。1 つずつ「。」で区切る）
2. **手札にある間**：手札にある間、〜コスト-N。
3. **場にいる間ずっと**：自分の場のほかの〇〇1体につき攻撃力+1。
4. **きっかけ**：【場に出たとき】 → 【突進で攻撃したとき】 → 〜するたび → 自分のターンの始めに → 自分のターンの終わりに → 相手のターンの始めに → 【破壊されたとき】（闇堕ちの姿は【場に出たとき】の代わりに【闇堕ちしたとき】）

- キーワードを先頭に置くのは、ハースストーン 97%・MTG 95%・ONE PIECE 85% と多数派
- きっかけは「場に出たとき」が先で「破壊されたとき」が最後（ハースストーン・ONE PIECE・Shadowverse で、2 つのきっかけがあるカードのほとんどがこの順）
- きっかけの書き出しは、同じきっかけの最初の文にだけ付ける（「【場に出たとき】草を2体出す。自分のライフを2回復する。」）
- **名前の付いたきっかけは【】のラベルにする**（10月24日。オーナー：「シャドーバース分かりやすいので、シャドーバースを参考にしてほしい」）：【場に出たとき】【突進で攻撃したとき】【破壊されたとき】【闇堕ちしたとき】。ラベルのあとに「、」は付けない。Shadowverse の【ファンファーレ】【ラストワード】【攻撃時】と同じ型。きっかけを記号で書くのは ONE PIECE 99%・Shadowverse 83%・ポケモンカード 80%・ハースストーン 48%
- 時の指定（手札にある間、・自分のターンの終わりに、・相手のターンの始めに、・〜するたび、）は、ラベルにせず文で書く（Shadowverse の「自分のターン終了時、」と同じ）
- 文の中でほかのきっかけを指すときも、ラベルで書く（「そのキャラクターの【場に出たとき】は働かない。」）

## 文の型

**動き 1 つを文 1 つにする**。2 つの動きを「〜し、〜する」でつながない。同じ対象が続くときは、2 つ目の文で「そのキャラクター」と書く（MTG 45%・Shadowverse 40%・遊戯王 36% が「その〜」「それ」で前の対象を指す。「〜し、〜」でつなぐのは遊戯王の 22% 以外ほぼ無い）。

| 動き | 書き方 |
|---|---|
| 引く | カードをN枚引く |
| ダメージ | 相手のキャラクター1体にNダメージ／相手のキャラクターすべてにNダメージ／相手のプレイヤーにNダメージ |
| 数で増えるダメージ | 自分の場のキャラクター1体につき、相手のプレイヤーにNダメージ／相手のキャラクターすべてに、相手のキャラクター1体につきNダメージ |
| 破壊 | 相手のキャラクター1体を破壊する／体力がN以下の相手のキャラクターすべてを破壊する |
| 回復 | 自分のライフをN回復する／自分のキャラクターすべてと自分のライフをN回復する |
| 強化 | 自分のキャラクター1体に攻撃力+N・体力+N／自分のほかのキャラクターすべてに攻撃力+N |
| 自分の強化 | 攻撃力+N・体力+N（主語を書かない） |
| このターンだけの強化 | このターン攻撃力+N |
| 弱体 | 相手のキャラクター1体の攻撃力-N |
| 状態 | 相手のキャラクター1体を眠り状態にする／晒し状態にする／沈黙状態にする |
| 続けて同じ対象に | 相手のキャラクター1体に3ダメージ。そのキャラクターを晒し状態にする |
| キーワードを付ける | 自分のキャラクターすべてに速攻を付ける／突進を付ける |
| トークン | 草をN体出す／自分の空いている枠すべてに草を出す／自分の空いている枠に、トークンとしてこのキャラクターのコピーを1体出す |
| 戻す | 相手のキャラクター1体を持ち主の手札に戻す |
| 奪う | 攻撃力がN以下の相手のキャラクター1体を奪う |
| 探す | 山札から〇〇界隈のカードを1枚探して手札に加える。なければカードを1枚引く |
| 蘇生 | 墓地のコストがN以下の自分のキャラクターのうち、コストがいちばん高い1体を場に戻す。【場に出たとき】も働く |
| プレイヤーに付ける効果 | 相手のプレイヤーに「〜」効果を付与する（「〜」の中は、付けられた側から見た「自分の」で書く） |
| ガードを無視 | このターン、自分のキャラクターすべてはガードを無視して攻撃できる |
| 〜するたび | 自分が回復の効果を使うたび、〜／相手のキャラクターを破壊するたび、もう1回攻撃できる |

### 条件

- **条件のあとは「、」で区切る**：「手札が3枚以下なら、カードを1枚引く。」「自分の場にアイドル界隈がいれば、カードを1枚引く。」（どのゲームも「〜なら、」「〜場合、」と区切る）
- 数を見る条件は「自分の場に〇〇属性が3体以上いれば、」。1 体以上は「自分の場に〇〇界隈がいれば、」
- 前の動きに条件付きで重ねるときは「さらに」：「カードを1枚引く。手札が3枚以下なら、さらにカードを1枚引く。」

### 対象の書き方

- **誰のか**を必ず書く：自分の〜／相手の〜／自分のほかの〜（ONE PIECE 91%・Shadowverse 82%・遊戯王 58% が「自分の」「相手の」で書く）
- **選ぶ対象**：相手のキャラクター1体（遊ぶ人が選ぶ。「選ぶ」とは書かない。ハースストーンの型）
- **自動で決まる対象**：攻撃力がいちばん高い相手のキャラクター1体／コストがいちばん高い相手のキャラクター1体
- **条件で絞ってから自動で決まる対象**：攻撃力が N 以下の相手のキャラクターのうち、攻撃力がいちばん高い1体
- **ランダム**：ランダムな自分のほかのキャラクター1体
- **すべて**：「すべて」（「全て」「各〜」は使わない）
- 数は「1体」「N枚」を必ず付ける。キャラクターの効果で味方すべてを指すときは「自分のほかの〜」（自分を含めない）

### 期間

- 「このターン」「このターンの終わりに」（ハースストーン・遊戯王・ONE PIECE の型。MTG の「ターン終了時まで」は使わない）

## 使わない書き方

| 使わない | 代わりに |
|---|---|
| 括弧（ ）での説明・補足 | 語の説明は解説の小窓へ。条件・例外は文にする（「センターに出したときは、左右に2体出す。」） |
| 状態の中身を書く（「眠らせる（次のターン攻撃できない）」） | 「眠り状態にする」 |
| 状態を動詞で書く（眠らせる・晒す・訂正する） | 「〇〇状態にする」 |
| 2 つの動きを 1 文にする（「沈黙状態にし、攻撃力-2」） | 「沈黙状態にする。そのキャラクターの攻撃力-2」 |
| すぐ攻撃できる（ようになる） | 「速攻を付ける」（相手のキャラクターにだけなら「突進を付ける」） |
| 「×」での掛け算（「相手のキャラクターの数×2ダメージ」） | 「相手のキャラクター1体につき2ダメージ」 |
| 用語集にない呼び名（アイコン・投稿・オワコン・話題力・マスター・界隈・倒す・墓場・ドロー・召喚・登場時） | 用語集の呼び名 |
| +N/+N | 攻撃力+N・体力+N（画面の数字の表示には使ってよい） |
| 全角の数字 | 半角の数字（ハースストーン・ONE PIECE・ポケモンカード・Shadowverse は半角） |
| フレーバー（セリフ・雰囲気の文）・肩書き | 書かない（カードのデータにも項目が無い。[working-agreement.md](working-agreement.md)） |

## 新しい語を足すとき

1. [glossary.md](glossary.md) に呼び名・意味・コードの名前を足す（王道のゲームでの言い方も調べて書く）
2. 解説の小窓（`apps/web/src/help/help.ts`）に、押したときの説明を足す
3. カードには名前だけを書く

## テストで確かめていること

- 効果文が、効果データから組み立てた文と同じ（`text.test.ts`）。並び・文の型・条件・対象の書き方は、ここで決まる
- **1 枚の効果文は 100 字まで**（`text.test.ts`。10月24日にオーナーが決めた。今いちばん長いのは『演出家』の 100 字）
- 使わない呼び名が無い（カード名の中は除く）
- 括弧・全角の数字・「N/N」が無い
- 文の終わりが「。」
- キーワードが、決まった順に先頭にある
- 「〇〇状態」は用語集に登録した状態だけ
- 解説の小窓の文も、使わない呼び名を使っていない。押せる語と使わない呼び名は、すべて glossary.md に載っている
- 画面の文字（`apps/web/src`・`packages/game-core/src`・`apps/api/src` の文字列。コメントは除く）にも、使わない呼び名が無い（各パッケージの `terms.test.ts`）

## 決まった改訂（10月24日）

調べ（[research/card-text/README.md](research/card-text/README.md)）から出した案に、オーナーが決めたこと。

1. きっかけは Shadowverse に寄せて【】のラベルにする（上の「文の並び」）
2. 1 枚の効果文は 100 字まで（テストで落とす）
3. 選ぶ対象に「選ぶ」とは書かない（ハースストーンの型。画面で選ぶ操作がある）
4. コピペの「トークンとして」は残す（説明ではなく、手札に戻ると消えるという効果の一部）
