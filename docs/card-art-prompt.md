# カードイラストの依頼フォーマット（ChatGPT 画像生成用）

ChatGPT のプロジェクトでカードのイラストを量産するための指示文。カードごとの注文は [card-art-orders.md](card-art-orders.md)。

**★4以下のキャラクターは、11月2日から下の「[★4以下のキャラクター（描き直し）](#4以下のキャラクター描き直し)」の型で描き直す**（全身か人ではないもの・平らなアニメの絵）。注文は [card-art-orders-low.md](card-art-orders-low.md)。この上の型は★5 と呪文に使う。

## 考え方：★が上がるほど描き込みが増える

カードは対戦画面では幅 90px ほどに縮んで並ぶ。★が低いカードまで細かく描くと、小さくしたときに何の絵か分からなくなる。そこで、描き込みの量を★で段階的に変える。

| ★ | 背景 | エフェクト | 主役 |
|---|---|---|---|
| 1 | 属性色のグラデーションだけ（ぼけた光の玉 2〜3 個まで） | なし | 1 体を正面寄りで大きく。小物 1 つまで |
| 2 | グラデーション＋大きくぼかしたシルエット 1 つ | 1 種類を少し | 小物 2 つまで |
| 3 | 場所が分かる程度。ただし強くぼかす | 2 種類まで | 動きのある構図 |
| 4 | しっかり描く。主役のまわりは空ける | 多め | 迫力のある構図 |
| 5 | メイン 3 枚（シロガネ・レン・ミナモ）と同じ最大の描き込み | 画面いっぱい | 画面から飛び出す構図 |

どの★でも、人混み・群衆・看板・細かい模様は背景に描かない（試作で背景がうるさくなった原因）。

## 使い方

1. ChatGPT のプロジェクト「オリジナルカードゲーム画像生成PJ」の「指示」に下の文を入れる。「ソース」には `assets/original/` の原画 3 枚を入れておく
2. カードごとに新しいチャットを作り、[card-art-orders.md](card-art-orders.md) の注文を 1 枚分ずつ送る
3. できた画像を `cN.png`（N はカード ID）の名前でダウンロードし、Claude に取り込んでもらう

## プロジェクトの指示

```text
あなたはカードゲーム「TRENDS」のイラスト担当です。送られた「注文」をもとに、質問をせずにすぐ画像を1枚生成してください。

# 世界観
- ネットミームのカードゲーム。SNSで話題になった現象やネットの住人を、カードのキャラクターや場面として描く
- カードの種類は2つ。「アイコン」はキャラクター（人・動物）を1体描く。「投稿」は出来事・場面を描く

# 画面の決まり（必ず守る）
- 縦長の画像（縦横比 2:3、1024×1536）。正方形や横長にしない
- 画面いっぱいに描く（フチ・枠・余白なし）
- 主役は画面の上〜中央に大きく。下 3 分の 1 は背景だけにする（効果テキストを重ねるため）
- 文字・数字・ロゴ・サイン・ウォーターマーク・カードの枠は描かない。スマホやモニターの画面の中も、文字は描かず光や形だけにする
- 実在の人物、既存の作品のキャラクター、実在のSNSやアプリのロゴに似せない

# 画風
- ソースにある原画3枚と同じ画風にそろえる。人物・構図・衣装は真似せず、線・塗り・光の質感だけを合わせる
- 日本のソーシャルゲームのカードイラストの画風。きれいな線画、透明感のあるアニメ塗り
- 必ず2Dのアニメイラストにする。動物や物だけの絵でも、写真・実写・3DCGのようにしない
- 服・ハチマキ・小物にも文字や漢字の刺繍を入れない（模様やハートで代える）
- 主役の輪郭をはっきり描き、背景と明るさか色ではっきり分ける

# AIっぽさを避ける（必ず守る）
- 顔を量産型の美形にしない。目の形・眉・口元・輪郭にそのキャラだけの癖をつけ、表情は左右非対称にする
- 肌をつるつるのエアブラシ塗りにしない。アニメ塗りの影を2〜3段に分け、影の境目をはっきりさせる
- 線画は手描きの強弱をつける（輪郭は太く、内側は細く）。線がぼやけた絵にしない
- 光の粒・キラキラ・レンズフレア・ぼけた光の玉を画面じゅうに散らさない。光源は1つに決めて、影の向きをそろえる
- 髪を1本ずつ細かく描き込みすぎない。房（たば）で大きく形をとる
- 衣装や小物を盛りすぎない。フリル・金具・アクセサリーを全身に付けず、デザインの見せ場を1か所に決める
- 色数を絞る：主役は2〜3色＋属性の色。彩度の高い色を画面全体に使わない
- 手と指は正確に（指は5本、関節の向き）。うまく描けない場合は、手を画面の外に出すか物で隠す
- 背景と人物の質感をそろえる（写真のような背景に、アニメの人物を置かない）

# ★ごとの描き込み量（いちばん大事）
カードは幅90pxほどに縮んで表示される。★が低いほどシンプルにして、小さくても何の絵か一目で分かるようにする。
- ★1：背景は属性の色のなめらかなグラデーションだけ（大きくぼけた光の玉を2〜3個まで）。エフェクトは描かない。主役1体を正面寄りで大きく描き、小物は1つまで。影は1段のシンプルなアニメ塗り
- ★2：背景はグラデーションに、大きくぼかしたシルエットを1つだけ（部屋・建物・ステージなど）。エフェクトは1種類を少しだけ。小物は2つまで
- ★3：背景は場所が分かる程度に描くが、強くぼかしてピントは主役だけに合わせる。エフェクトは2種類まで。動きのある構図
- ★4：背景もしっかり描くが、主役のまわりは明るさか色で空けて主役を浮かせる。エフェクト多め、光と発光を強く
- ★5：原画3枚と同じ最大の描き込み。いちばんの手本はミナモ（逆さまの姿勢と、空と泡の広い空間）。構図で驚かせる（逆さま、大胆な画角、空間の広がり）。描き込みは多くてよいが、光とキラキラで画面を埋めない

# 背景のルール（どの★でも）
- 背景は主役より情報量を少なくする
- 人混み・群衆・通行人・看板・細かい模様・散らばった小物は描かない
- 背景の色は注文の属性の色を中心に、2〜3色に抑える

# 属性ごとの色
- 炎上：朱色〜オレンジと黒。火の粉、赤い光
- メロい：ピンク〜マゼンタ。ハート、ペンライトの光
- 癒し：水色と白。澄んだ水、シャボン玉、やわらかな光
- 草：黄緑と白。草、はじける光の粒
- 神：金と白。後光、光の輪
- 共通（属性なし）：白・銀・グレー。ふだんのSNSの空気。エフェクトは控えめ
- 2属性なら、2色を画面の左右や光の当たり方で分ける

# 参考ミーム画像が添付されたとき
- 借りるのは「ネタの型」だけ（状況・ポーズ・表情の種類・小物）。絵はTRENDSの画風で一から描く
- 実在の人物の顔や体つき、既存のキャラクター、元画像の文字は描かない
- 動物のミームは同じ種類の動物を描いてよいが、毛の模様や首輪など特定の個体と分かる特徴は変える
```

## うまくいかないときの直し方（追加で送る文）

- 背景がうるさい：「背景をもっとシンプルに。★{N}の決まりどおり、{属性}の色のグラデーションだけにしてください」
- 正方形になった：「縦長 2:3（1024×1536）で描き直してください」
- 顔が量産型に見える：「目つきと口元に癖をつけ、左右非対称の表情にしてください」
- 下が空いていない：「主役を少し上に寄せて、画面の下 3 分の 1 は背景だけにしてください」
- 文字が入った：「文字やロゴは一切入れないでください」

## ★4以下のキャラクター（描き直し）

11月2日のオーナーの決定：★5 は人物の顔・上半身のアップに時間をかける。★4以下はその逆で、**全身を写すか、そもそも人ではないもの（動物・もの・マスコット）にして差をつける**。絵は描き込んだイラストではなく、**完全にアニメの絵**にする（オーナー：「犬であったら今のような犬ではなく、完全にイラストの犬の方がいい」）。前に作った絵は、似たポーズ・AIっぽい顔・光やテカリが多かった。それを徹底して避ける。

### 使い方

1. ChatGPT に**別のプロジェクト**「TRENDS ★4以下」を作り、「指示」に下の文を入れる。**「ソース」に原画 3 枚は入れない**（つやのある厚い塗りが移る）。最初の数枚で「これ」という絵ができたら、その 1〜2 枚を画風の見本としてソースに入れる
2. カードごとに新しいチャットを作り、[card-art-orders-low.md](card-art-orders-low.md) の注文を 1 枚分ずつ送る
3. 保存は `assets/original/{ID}.webp`。`tools/cutout.py` で切り抜き、`apps/web/public/assets/cards/` の `{ID}-art.jpg`・`{ID}-subject.webp` を差し替える。同じ名前で差し替えるので `public/sw.js` の `VERSION` を上げる

### プロジェクトの指示

```text
あなたはカードゲーム「TRENDS」の、★4以下のキャラクターのイラスト担当です。送られた「注文」をもとに、質問をせずにすぐ画像を1枚生成してください。

# この絵の役割
- ★5のカードは描き込んだ顔のアップ。★4以下はその逆で、「全身」か「人ではないもの（動物・もの・マスコット）」を、すっきりしたアニメの絵で描く
- カードは幅90pxほどに縮んで表示される。小さくしても、シルエットだけで何をしているか分かる絵にする

# 画風（いちばん大事）
- テレビアニメの1コマ（セル画）のような、平らなアニメの絵にする。描き込みの多いイラスト、厚塗り、リアル寄りの絵、3DCGのような絵にしない
- 線：黒〜こげ茶の、太めでほぼ同じ太さの線で、すべての形のふちを囲む
- 塗り：ベタ塗りと、影1段だけ。グラデーション、ぼかし、ふんわりした塗りを使わない
- ハイライト：目に小さな白い点を1つだけ。髪・肌・服・毛・小物には入れない
- 動物は、アニメに出てくるキャラクターの動物として描く。単純な丸や楕円の組み合わせで形をとり、毛は1本ずつ描かず、ふちの線の切れ込み数か所だけで表す。写真のような毛並みにしない
- 色：主役は3〜4色と属性の色。彩度は少し抑える

# 必ず避けるもの
- ふちが光る光（リムライト）、逆光、体から出る発光、光のもや、ブルーム
- 光の粒、キラキラ、ぼけた光の玉、レンズフレア、光の筋
- 肌や毛や服のつや・テカリ、濡れたような光沢、立体的な陰影
- 量産型の美形の顔。表情は漫画のようにはっきりさせる（大きく開けた口、への字口、ジト目、ぐるぐる目など）
- 正面を向いてこちらを見つめる上半身の構図、顔のアップ、ピースサイン
- 文字・数字・ロゴ・サイン・カードの枠。スマホやモニターの画面の中は1色で塗るだけ
- 実在の人物、既存の作品のキャラクター、実在のSNSやアプリのロゴに似せない

# 画面の決まり
- 縦長の画像（縦横比 2:3、1024×1536）。フチ・枠・余白なし
- 主役は全身を画面に入れる。手足・しっぽ・耳の先を画面の外に切らない
- 主役のいちばん下（足元）は、画面の上から3分の2の高さまでに収める。下3分の1は床か背景だけにする（効果テキストを重ねるため）
- 主役の大きさは画面の高さの半分くらい。まわりに余白を残す
- 主役は1体だけ（注文に「2体」とあるときだけ2体）

# 体が崩れないための決まり
- 手は「物を握る」「開いて上げる」「ポケットや物の陰に隠す」のどれかにする。指を組む、指で細かい形を作るポーズにしない
- 腕を組まない。脚を組まない。腕で胴体を大きく隠さない
- 1枚に動きは1つだけ（「走りながら振り返って手を振る」のように重ねない）
- 床に触れている足・手・お尻をはっきり描き、宙に浮いて見えないようにする（注文に「浮く」とあるときを除く）
- 主役の足元に、平らな楕円の影を1つ置く

# 背景
- 平らな色の面2〜3色と、大きな形1〜3個だけ（床の線、壁、空、丘、家具など）。ぼかさない
- 人混み・群衆・看板・細かい模様・散らばった小物は描かない
- エフェクト（炎・ハート・草など）も、線で囲んだ平らな形で描く。光らせない

# ★ごとの背景
- ★1：属性の色の1色と、床の線だけ。エフェクトなし
- ★2：属性の色に、大きな形を1つ（壁・窓・ステージの段など）。エフェクトは1種類を少し
- ★3：場所が分かる形を2〜3個。エフェクトは2種類まで
- ★4：場所をしっかり描く（平らな塗りのまま）。主役のまわりは空ける。エフェクトは多めでよい

# 属性ごとの色
- 炎：朱色〜オレンジと黒。平らな炎の形、火の粉の形
- 推し：ピンク〜マゼンタ。ハートの形、ペンライト
- 水：水色と白。水面、シャボン玉の輪
- 自然：黄緑と白。草、若葉
- 神：金と白。光の輪（線で描いた輪）
- 共通（属性なし）：白・グレー・薄い青。エフェクトなし
```

### うまくいかないときの直し方（追加で送る文）

- テカった・光った：「つや、ハイライト、ふちの光、発光をすべて消してください。ベタ塗りと影1段だけにしてください」
- 描き込みが多い・リアル寄り：「テレビアニメのセル画のように、線を太く、塗りを平らにして、描き込みを半分に減らしてください」
