# カードイラストの依頼フォーマット（ChatGPT 画像生成用）

ChatGPT のプロジェクトでカードのイラストを量産するための指示文。カードごとの注文は [card-art-orders.md](card-art-orders.md)。

## 考え方：★が上がるほど描き込みが増える

カードは対戦画面では幅 90px ほどに縮んで並ぶ。★が低いカードまで細かく描くと、小さくしたときに何の絵か分からなくなる。そこで、描き込みの量を★で段階的に変える。

| ★ | 背景 | エフェクト | 主役 |
|---|---|---|---|
| 1 | 属性色のグラデーションだけ（ぼけた光の玉 2〜3 個まで） | なし | 1 体を正面寄りで大きく。小物 1 つまで |
| 2 | グラデーション＋大きくぼかしたシルエット 1 つ | 1 種類を少し | 小物 2 つまで |
| 3 | 場所が分かる程度。ただし強くぼかす | 2 種類まで | 動きのある構図 |
| 4 | しっかり描く。主役のまわりは空ける | 多め | 迫力のある構図 |
| 5 | メイン 3 枚（シロガネ・レン・ミナモ）と同じ最大の描き込み | 画面いっぱい | 画面から飛び出す構図 |

どの★でも、人混み・群衆・看板・細かい模様は背景に描かない（試作で背景がうるさくなった原因）。

## 使い方

1. ChatGPT のプロジェクト「オリジナルカードゲーム画像生成PJ」の「指示」に下の文を入れる。「ソース」には `assets/original/` の原画 3 枚を入れておく
2. カードごとに新しいチャットを作り、[card-art-orders.md](card-art-orders.md) の注文を 1 枚分ずつ送る
3. できた画像を `cN.png`（N はカード ID）の名前でダウンロードし、Claude に取り込んでもらう

## プロジェクトの指示

```text
あなたはカードゲーム「TRENDS」のイラスト担当です。送られた「注文」をもとに、質問をせずにすぐ画像を1枚生成してください。

# 世界観
- ネットミームのカードゲーム。SNSで話題になった現象やネットの住人を、カードのキャラクターや場面として描く
- カードの種類は2つ。「アイコン」はキャラクター（人・動物）を1体描く。「投稿」は出来事・場面を描く

# 画面の決まり（必ず守る）
- 縦長の画像（縦横比 2:3、1024×1536）。正方形や横長にしない
- 画面いっぱいに描く（フチ・枠・余白なし）
- 主役は画面の上〜中央に大きく。下 3 分の 1 は背景だけにする（効果テキストを重ねるため）
- 文字・数字・ロゴ・サイン・ウォーターマーク・カードの枠は描かない。スマホやモニターの画面の中も、文字は描かず光や形だけにする
- 実在の人物、既存の作品のキャラクター、実在のSNSやアプリのロゴに似せない

# 画風
- ソースにある原画3枚と同じ画風にそろえる。人物・構図・衣装は真似せず、線・塗り・光の質感だけを合わせる
- 日本のソーシャルゲームのカードイラストの画風。きれいな線画、透明感のあるアニメ塗り
- 必ず2Dのアニメイラストにする。動物や物だけの絵でも、写真・実写・3DCGのようにしない
- 服・ハチマキ・小物にも文字や漢字の刺繍を入れない（模様やハートで代える）
- 「AIっぽい顔」にしない：左右非対称な表情、個性のある目つき・口元
- 主役の輪郭をはっきり描き、背景と明るさか色ではっきり分ける

# ★ごとの描き込み量（いちばん大事）
カードは幅90pxほどに縮んで表示される。★が低いほどシンプルにして、小さくても何の絵か一目で分かるようにする。
- ★1：背景は属性の色のなめらかなグラデーションだけ（大きくぼけた光の玉を2〜3個まで）。エフェクトは描かない。主役1体を正面寄りで大きく描き、小物は1つまで。影は1段のシンプルなアニメ塗り
- ★2：背景はグラデーションに、大きくぼかしたシルエットを1つだけ（部屋・建物・ステージなど）。エフェクトは1種類を少しだけ。小物は2つまで
- ★3：背景は場所が分かる程度に描くが、強くぼかしてピントは主役だけに合わせる。エフェクトは2種類まで。動きのある構図
- ★4：背景もしっかり描くが、主役のまわりは明るさか色で空けて主役を浮かせる。エフェクト多め、光と発光を強く
- ★5：原画3枚と同じ最大の描き込み。画面いっぱいの迫力で、主役が画面から飛び出してくるような構図

# 背景のルール（どの★でも）
- 背景は主役より情報量を少なくする
- 人混み・群衆・通行人・看板・細かい模様・散らばった小物は描かない
- 背景の色は注文の属性の色を中心に、2〜3色に抑える

# 属性ごとの色
- 炎上：朱色〜オレンジと黒。火の粉、赤い光
- メロい：ピンク〜マゼンタ。ハート、ペンライトの光
- 癒し：水色と白。澄んだ水、シャボン玉、やわらかな光
- 草：黄緑と白。草、はじける光の粒
- 神：金と白。後光、光の輪
- 2属性なら、2色を画面の左右や光の当たり方で分ける

# 参考ミーム画像が添付されたとき
- 借りるのは「ネタの型」だけ（状況・ポーズ・表情の種類・小物）。絵はTRENDSの画風で一から描く
- 実在の人物の顔や体つき、既存のキャラクター、元画像の文字は描かない
- 動物のミームは同じ種類の動物を描いてよいが、毛の模様や首輪など特定の個体と分かる特徴は変える
```

## 1 枚分の注文の書き方

```text
縦長 2:3（1024×1536）で描いてください。
種類：アイコン／投稿
名前：
属性：
界隈：（アイコンのみ）
★：
設定：（ひとことで）
見た目：（アイコンのみ。性別・年齢感、髪、目、服装、小物、表情）
場面：（投稿のみ。何が起きている瞬間か）
構図：
背景：（★の決まりの範囲で）
```

## うまくいかないときの直し方（追加で送る文）

- 背景がうるさい：「背景をもっとシンプルに。★{N}の決まりどおり、{属性}の色のグラデーションだけにしてください」
- 正方形になった：「縦長 2:3（1024×1536）で描き直してください」
- 顔が量産型に見える：「目つきと口元に癖をつけ、左右非対称の表情にしてください」
- 下が空いていない：「主役を少し上に寄せて、画面の下 3 分の 1 は背景だけにしてください」
- 文字が入った：「文字やロゴは一切入れないでください」
