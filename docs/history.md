日付は 2026 年。PR の番号は GitHub の Kanta-Yamamoto/trends-cardgame。進め方の決まりは [working-agreement.md](working-agreement.md)。

## 10月17日：ルール v3〜v4、カード、オンライン、公開

- 設計メモ（`docs/design-v3.md`）：属性（炎上・メロい・神・草・癒し）、界隈、★、カードの種類（アイコン・投稿）、闇堕ち、山札25枚・同名3枚・後攻の補正、ガード
- 全カードのイラストを入れ、★ごとに描き込み量を変える。★4〜5 はキラデザイン、★5 は専用デザイン
- 第2弾でカード37枚追加。共通カード、属性2つまでのデッキ
- ルール v4：★4〜5 を属性の勝ち方を体現する切り札にする。特攻はやめ、勝ち方の癖で相性が出る形に（#2）
- オンライン対戦：Google ログイン・合言葉の部屋・Socket.IO の同期・再接続、相手の操作を大きく見せる・手札が多いときに広げる（#3）
- 公開：API が Web も配る1つの Cloud Run。最初だけ Cloud Shell（`infra/bootstrap.sh`）、以降は GitHub Actions の Terraform。設定は `infra/gcp.env`。DB は Neon（#4〜#9）
- 本番でカード一覧が空 → 起動時に seed を入れる（#10）

## 10月17〜18日：スマホで遊んでもらったフィードバック

- カードを画面いっぱいに拡大して効果を読む（#11）
- PWA（ホーム画面に追加・全画面・オフラインで CPU 戦）（#12）

- 枠を選んで出す・デッキの確認・ターン終了の確認・スマホの画面合わせ（iPhone のセーフエリア、Android の横長）（#14）
- CPU を先読み（ビームサーチ）に。これまでの CPU に約8割勝つ。投稿・登場時の効果に演出（#15）
- 先読み CPU 同士だと、炎上が強く推しが弱い（次のバランス調整の基準）

## 10月18日：カード一覧とインストールの案内

- カード一覧を★5 から★ごとの段に並べ、縦持ちのスマホは段ごとに横スワイプ。属性で絞り込み。押すと効果を大きな文字で読める拡大表示
- 初めての人に、ホーム画面に追加する手順をスクショ付きで案内（Android は Chrome のメニュー、iPhone は Safari の共有）
- 進め方の決まりと経緯を `docs/working-agreement.md`・`docs/history.md` にまとめる

## 10月18日：手札の扇・闇堕ちの絵・第3弾

- 手札を扇のように持つ（PC はホバー、スマホは選ぶと持ち上がる）
- 闇堕ちしたアイコンが真っ暗だったのを直す。デザインはそのままで、絵・名前・効果・数値だけを闇堕ちのものに。今は元の絵を紫に塗り直した仮の絵で、ChatGPT への注文を `docs/card-art-orders.md` に追加
- 試作（ガチャ演出・対戦フィールド）を削除
- 癒しを根本から強く：「回復するたびに」働く仕組み（強くなる・相手にダメージ・回復の回数だけ安くなる）。シャドバの回復ビショップを参考に
- 全属性に★1〜★5 を5枚ずつ、計25枚追加（第3弾）。イラストはまだ無く、注文を `docs/card-art-orders.md` に追加
- 先読み CPU のシミュレーションでコストとデモ用デッキを調整し、デッキの勝率を 42〜57% に（調整前 17〜76%）

## 10月18日：第3弾と闇堕ちのイラスト

- ChatGPT（Claude in Chrome で操作）で第3弾25枚と闇堕ち5枚の絵を描き、取り込む。元の画像は `assets/original/`
- k11 www連打勢は妖精の注文が断られたので、黄緑パーカーの男の子に。c8 ワラも人間の少年に

## 10月18日：友人のフィードバック

- 手札を枠・相手へ、場のアイコンを攻撃先へドラッグして出す・投稿・攻撃（Pointer Events でスマホのブラウザでも動く。タップでの操作もそのまま）。攻撃と対象を取る投稿は矢印で狙う
- 攻撃先を選ぶと、与えるダメージ・叩き+2・倒せる／相打ち／倒されるを攻撃先に出す（計算は game-core の `previewAttack`、実際の攻撃と同じ）
- 投稿のカードを白い吹き出しの枠と「投稿」札にして、アイコンと見分けやすく

## 10月18日：デッキを10個に、★5の専用デザイン

- 属性の組み合わせ10通りすべてにデッキを用意（推しが炎上・燃えても癒える・草にマジレス・推しを考察・ゆるいTL を追加）。自由なデッキ作りは、この10個の調整が終わってから
- 先読み CPU 同士の総当たり（`packages/game-core/scripts/balance.mjs`）で調整。伝説のコラ画像は強すぎたので、コスト 9→10・ほかのアイコンの攻撃力+2 をなくす。ワラはコスト 7→6・体力 4→5。論破で炎上の論破王を外す
- カグラ・アイリ・ヨミ・ワラ・ユズハに★5の専用デザイン（#21）

## 10月18日：推しと闇堕ち（v5）

- ★5 を「推し」として推し枠に置く形に。推しはいつでも出せて、倒されたら1回だけ闇堕ちしてオワコンから戻ってくる（[design-v5.md](design-v5.md)）
- 倒されたら自動で裏返る闇堕ちはやめる。闇堕ちのときは画面全体の演出
- 10デッキの推しを決め、推しのコストを4〜6に、出たときの効果を盤面除去中心に組み直す。闇堕ちの姿がなかった5枚（シロガネ・ヨミ・ワラ・カグラ・ユズハ）に闇堕ちの姿（絵は仮）

## 10月18日：推し枠をやめる（v5.1）

- 推し枠に★5を固定すると、そこまでのドローが意味を持たなくなるので、★5は山札に戻して手札から出す（各デッキ1枚）
- 闇堕ちは、闇堕ちを持つカードがオワコンに行ったら、自分のターンの好きなときにコストなしで出せる形に（1枚1回。出たターンは攻撃できない）。オワコンが光り、押すと闇堕ちさせるカードを選べる

## 10月18日：闇堕ちの個性と、呼び戻す枠の案内

- 闇堕ちさせるカードを選んだあと、何をすればいいか分からなかったので、「〇〇を、どこに呼び戻す？」の案内と、紫に光って波紋が広がる空き枠（「ここに呼び戻す」）を出す
- 「闇堕ちしたとき」が全体2ダメージに偏っていたので、属性ごとに散らす：ナギ＝相手全体を眠らせる、ヨミ＝いちばん強い相手を確定で倒す、シロガネ＝いちばんコストの高い相手を手札に戻す、ユズハ＝次の相手のターンまでマスターがダメージを受けない、ワラ＝草を2体出して味方を強化（カグラの全体2ダメージ、レン・アイドル・陰謀論者・コラ画像はそのまま）
- 新しい効果：確定除去（destroy）・手札に戻す（bounce）・マスターを守る（shieldMaster）

## 10月18日：界隈を軸に（v6 の土台）

- 界隈が属性の言い換えになっていた（草＝ミーム、神＝有識者）ので、属性＝勝ち方・デッキの決まり、界隈＝場で手を組む相手、と軸の仕事を分ける（[design-v6-kaiwai.md](design-v6-kaiwai.md)）
- 属性を 1 枚 1 つに（ミナモ→癒し、論破系配信者→炎上、踊ってみた→草）。界隈を属性をまたいで付け直し、2 界隈を 7 枚（ミナモ＝配信者＋アイドル、猫ミーム＝ミーム＋動物 など）
- 対戦中のカードに界隈の印（黒い四角に 配・ア・有・動・ミ）
- 界隈を読む効果・トレンドは次の PR から
