# 攻撃モーションの基準：『調停者』の突き（2026-10-23）

オーナー：「攻撃モーションの例として PJ のメモリーに蓄積しておいて。今後これを変えていく方で話をすると思う」。今後の攻撃・除去の演出は、この『調停者』の突きを土台に、どこを変えるかで話す。

- 実装：`apps/web/src/fx/thrust.ts`（呼ぶのは `apps/web/src/game/fx.ts` の `animateJudge`、きっかけは `pages/Play.tsx` の `resolveEffects` の `judge`）
- モック：claude.ai の Artifact「『調停者』の突き」（1/3・1/10 の速さで見られる。盤面の横に場面の表）
- バトル場は今の『調停者』の青のフィールド（`game/ArbiterField.tsx`）のまま。着地と同時に入る

## 1. 流れと秒数（1 体目の着地から）

| 時刻 | 場面 | 中身 |
|---|---|---|
| 0.00 | 着地 | ふだんの★5 の着地（`fx/fieldEntry.ts`）。着地の瞬間（`fx-landed`）から数える |
| +0.10 | 引きの溜め 0.2 秒 | 『調停者』が対象と逆へ 8px 下がる（ease-out 2 乗）。カードの前（対象の向き）に十字の星と光の玉が集まる |
| +0.30 | 発射 0.07 秒 | 光線が対象を突き抜けて、盤面のふちまで一直線に伸びる（ease-in 2 乗）。発射の反動で『調停者』が少し前へ出て戻る |
| +0.37 | 当たる | 対象が白く飛ぶ（明るさ 3 倍・色を抜く）。光線がいちばん太く明るい |
| +0.41 | 時が止まる 0.3 秒 | 盤面の色が反転し、すべてが止まる（GSAP の時計も止める）。**途切れた弧の波紋だけは止まらず、回りながらゆっくり広がる**（全部止めると処理が固まったように見えるため） |
| +0.71 | 動き出す | 光の筋と粒が飛び散る。波紋は加速して広がり切る。盤面が大きく揺れ、まわりのアイコンが波に押されて揺れる。対象はその場で一瞬ふくらんで震える。光線は両側からしぼんで消える |
| +1.17 | いつもの消え方 | 当たってから 0.5 秒後（止まっていた時間を除く）。ふだんオワコンになるときと同じ（黒く沈む 0.26 秒 → 上からまだらに溶ける。煙と灰） |

- 対象が 2 体以上なら、0.72 秒（＋止まった 0.3 秒）ずつずらして順に突く。順番は game-core の出来事の順（自分の場 → 相手の場）。敵味方を区別しない
- 動きを減らす設定（prefers-reduced-motion）では出さず、すぐにいつもの消え方

## 2. 部品ごとの決まり

### 光線
- 両端が細く、まん中が太い一直線。白い芯＋青白い光＋青いにじみの 3 層（`lighter` で重ねる）
- 太さ：当たって止まる間 6.3px、そのあと 4.2px から 0 へしぼむ（0.3 秒）。オーナー：「ツキの線 0.7 倍くらいの細さ」
- 出どころは『調停者』のカードの、対象の向きの縁。突き抜けて盤面のふちまで

### 時が止まる
- 長さ 0.3 秒（0.2 → 0.5 → 0.3 と試して決めた）。止まる瞬間は、光線が突き抜け切った当たって 0.04 秒後
- 盤面ごと `invert(1) hue-rotate(180deg) brightness(1.4)`。光線・波紋も一緒に反転する
- 止まっている間：光線・対象・光の筋と粒・揺れは止まる。波紋だけ実際の時間で動く

### 波紋
- 途切れた弧（円を 3 つに切った弧、1 本 83°）を 5 重。1 本ずつ 0.05 秒遅れて出る
- 広がり方：止まっている間はゆっくり、動き出すと加速（半径は時間の 2.4 乗の ease-in。0.95 秒で広がり切る）
- 大きさ：カードの幅の約 0.2 倍から約 1.4 倍まで（内側の弧ほど少し小さい）。オーナー：「広がりを抑えて上限を小さく」
- 回り方：5 本とも同じ向きに一定の速さ（2.2 ラジアン／秒）。1 本ごとに向きを 0.7 ラジアンずらす
- 線：細い（1.9〜1.3px から 0.4px へ）。白に、青い光を少し。最後の 4 割で薄れて消える
- 中心は**カードの真ん中**（オーナー：「真ん中にしろ」）。そのため対象は位置を動かさない

### 衝撃（波紋以外）
- 圧の玉：中心が白く、カードの幅の 1.1 倍までふくらんで、すぐしぼむ
- 光の筋：18 本、放射状。突いた向きのほうへ長く、明るく
- 光の粒：22 粒、突いた向きへ噴き出し、少し落ちる
- 盤面の揺れ：最大 11px、0.48 秒で収まる（2 乗で減る）
- まわりのアイコン：衝撃からの距離に応じて遅れて届き、外へ押されて 1.5 往復揺れる（最大 9px）
- 対象：位置は動かさず、一瞬 1.08 倍にふくらみ、小刻みに回って震えて戻る（0.38 秒）

## 3. やめたもの（オーナーの指示）

- 左上から突き下ろす細い光の刃（「突き刺す方向意味わかんない」「ダサい釘みたい」）。刃は必ず出どころ（『調停者』）から対象へ
- 割れる・ひびの演出（「割れるエフェクトは不要」）
- 当たってすぐ真っ黒にする（「黒くなるの不要」）。消え方はいつもの消え方
- 正円の太い輪・楕円の輪・二重の輪（「円ダサい」）。菱形・光芒・六角形・V 字も候補から外れた
- 盤面そのものの歪み（pixi-filters の ShockwaveFilter と同じ考え方）：見た目は良かったが、カードが HTML なので SVG の displacement で掛けることになり、iPhone の Safari で重い・動かない心配があるのでやめた
- 数字（-6）の表示

## 4. 進め方の決まり

- 攻撃・除去の演出は、ゲームに入れる前に**動くモックで見せて**詰める（「事前に見せろ」）。案は複数並べ、遅い速さで見られるようにする
- 変えるときは、この表のどこを変えるか（秒数・形・数・強さ）で話す
- アイコンの動きは CSS の個別のプロパティ（`translate`・`scale`・`rotate`）で付け、着地などほかの演出の `transform` とぶつからないようにする
- 描くキャンバスは盤面（`.board`）の中に置く（盤面ごと反転・揺れさせるため）。舞台の拡大縮小を戻した座標で描く
