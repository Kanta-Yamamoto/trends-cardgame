# 進め方の決まり（オーナーからの指示）

この開発で、オーナー（山本）から受けた指示と、決まった進め方のまとめ。新しい会話・新しいセッションの Claude は、作業の前にここと `CLAUDE.md` を読む。経緯は [history.md](history.md)。

## 会話の仕方

- 日本語で、簡潔に。事実と必要なことだけ答える
- オーナーに質問しない。分からないところは妥当な前提を置いて進め、置いた前提を書く
- 指示された手段が目的に対して最適でないと思ったら、実行前に代替案・根拠・トレードオフを短く出す。ただし明示された制約や権限は勝手に変えない
- 正確さや最新の情報が要るときは Web で調べる
- 専門用語（インフラなど）を聞かれたら、概念から図や例えで説明する

## 開発の回し方

- 変更はブランチ → PR → CI（リント・型・テスト・ビルド・Docker・Terraform 検証）→ マージ。main にマージすると Cloud Run へ自動デプロイされる
- **マージはオーナーの一言（「マージして」「マージしよう」など）で行う**。言われていないものは PR まで作って待つ
- **オーナーが本番で対戦中のときは、勝手にリリースしない**（デプロイでサーバーが入れ替わり、オンライン対戦が切れるため）
- 試遊用のアーティファクト（claude.ai の公開ページ）は、画面を変えたら作り直して同じ URL に出す
- ゲームのルールは `packages/game-core` にだけ書き、テストを付ける。画面にルールを書かない
- スマホ（Pixel 8・iPhone）で遊ばれる前提で、縦横の画面で確かめてから出す
- **スマホで流行らせる前提。対戦画面は縦持ちが本番**（10月19日）。PC（横）とスマホ（縦）の両方の画面を保つのが難しくなったら、スマホだけにする（オーナーの指示）

## ゲームの方針

- ネットミームのカードゲーム。ライフ 20、ステータスは攻撃力と体力、用語は `docs/rules.md` の「用語」にそろえる
- 属性は 炎上・メロい・神・草・癒し の5つ。1枚に1つ（0は共通）。界隈（ミーム・アイドル・配信者・有識者・動物）は属性をまたいで付け、1枚に2つまで（2つは★3以上の少数）。界隈でデッキは縛らず、界隈を参照する効果は自分の側だけ。方針は `docs/design-v6-kaiwai.md`
- **特定の相手への明示的な特攻（○○に強い・弱い）は付けない**。どの相手とも戦えるようにし、相性は各属性の「勝ち方の癖」から自然に出す。並びは 炎上→メロい→神→草→癒し→炎上（炎上はスキャンダルでメロいに強い）
- ★5・★4 は属性の勝ち方を体現する、尖った切り札にする
- **初期リリースは単属性デッキだけ**（10月19日）。構築済みデッキは単属性の 5 つ、デッキの決まりは「属性 1 つ＋共通カード」（CPU 戦・オンライン戦・自分で組むデッキすべて）。5 属性の総当たりで、どの属性も 45〜55% に収める
- **属性は混ぜられるが、単属性が得をする作りにする**（10月19日。初期リリースのあと、2 属性を解禁するときの方針）。選択肢が多いと人は動かないので、実際は単属性が覇権を取りやすく、2 属性はその対策として使える形にする（シャドバも混ざらなかった）
- **方針メモ（まだカードは変えない）**：★5 などの強化の対象は、基本的に自分の属性か界隈に絞る。見直しの候補（★4・★5 で味方全体を強化・回復・すぐ攻撃させるもの）：伝説のコラ画像・ミーム女王（全員すぐ攻撃）、生誕祭・アイリ・トレンドメーカー・ワラ（通常と闇堕ち）・ミレイ（味方全体の強化）、ミナモ・ゆるキャラ・温泉宿の女将（味方全体の回復）
- ★5 は手札から普通に出す（推し枠はやめた）。闇堕ちを持つ★5は、倒されたら次の自分のターンの始めに自動で闇堕ちの姿で出る（コストなし・選ぶ操作なし。出たターンは相手のアイコンにだけ攻撃できる＝凸）。闇の姿が倒されたら消える。闇堕ちは★5だけ（普通のカードには配らない）（10月20日。それまでは「オワコンから自分で選んで出す」。経緯は `docs/design-v5.md` と `docs/design-v10-buzz.md`）
- **デッキは 20 枚・同じカードは 2 枚まで・闇堕ちを持つカードは 1 種類まで**（★5 の種類は制限しない）。闇堕ちの回数は決まりにせず、エース 2 枚で「最大 2 回」を感覚で分からせる（10月20日）
- **バズ**：1 試合 2 回、自分のアイコン 1 体に攻撃力+2・体力+2と凸。盤面を取り返す手段を、凸のカードに頼らずどのデッキも持てるように。シャドバの進化の丸写しにはしない（強化なので晒しで消える・マスターの技としてカットインで見せる）（10月20日）
- 闇堕ちを持つのは各属性 2 人。基本 6〜7 コストで、通常の姿はシンプル、闇の姿を強く（クサハミだけ低コストの例外）
- ゲームの仕組みはシャドバなど既存のゲームそのものにしない（進化の丸写しは不可）
- 実在の人物は描かない（例：野獣先輩は不可）
- 次のバランス調整は、先読みする CPU（`planTurnSearch`）同士の結果を基準にする（`docs/rules.md`）

## 画面・遊びやすさで受けたフィードバック

- スマホでは文字が小さい → 長押し・右の表示・「大きく見る」でカードを画面いっぱいに拡大
- アイコンは出す枠を自分で押したときだけ出す（2度押しで勝手に出さない）
- オンライン対戦のデッキは確認してから決める。ターン終了も確認を出す
- 対戦画面はセーフエリアを除いて舞台ごと収め、横長の画面では大きく使う
- 投稿・登場時の効果は、結果をすぐ出さず「飛んで・当たる」演出を見せてから盤面を変える
- カード一覧は★5 から並べ、スマホの縦持ちでは段ごとに横スワイプ
- 初めての人には、ホーム画面に追加（PWA）する手順をスクショ付きで案内する
- 友人のフィードバック（10月18日）：シャドバのようにドラッグ＆ドロップで出す・投稿・攻撃したい（タップ操作も残す）。投稿とアイコンを見分けやすく。叩きが使いにくい → 攻撃先に与えるダメージ・叩き+2・倒せるかを出す。属性を混ぜられるのは好評
