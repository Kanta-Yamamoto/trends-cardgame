# TRENDS 設計メモ（v3 に向けて決めたこと）

ルール v3 の前提として、話し合いで決まったことをまとめる。ルールの本文は決まり次第 `docs/rules.md` に反映する。

## コンセプト

ネットミームのカードゲーム。カードはネットで話題になった現象やキャラ。

## 決まっていること

- ステータスは攻撃力（赤）と体力（青）の2つ。マスターのライフは 20
- 攻撃すると、攻撃力の分だけ相手の体力を削る。受けたダメージは残る

## 属性（5つ）

1枚に最大2属性。2属性のカードは、枠を斜めに2色で塗り分ける。属性どうしの有利・不利（効果抜群など）は無く、属性は「そのカードが持ちやすい効果の傾向」を表す。

| 属性 | テーマ | 色 | マーク |
|---|---|---|---|
| 炎上 | 集団での連続攻撃（同じ相手を続けて叩くほど攻撃力が上がる、2回攻撃など） | 朱色 | 炎 |
| メロい | 注目と、それによる恩恵（注目がたまって育つ、注目を使って大きな効果） | ピンク | ハート |
| 癒し | 鎮める（相手のバインド、回復、山札を整える） | 水色 | しずく |
| 草 | 便乗と増殖（乗っかって発動、同じ型を量産、まとめて出すほど強い） | 黄緑 | w |
| 神 | 正しさと知識（訂正・打ち消し、隠れた情報を暴く、条件がぴったりで大効果） | 金と白 | 後光 |

色だけで区別しない（赤と緑は見分けにくい人がいる）。必ずマークを併記する。

### 属性の決め方

「その話題に人が何をしたか」で決める。

| 人がしたこと | 属性 |
|---|---|
| 叩いた | 炎上 |
| 推した・見とれた | メロい |
| 癒やされた | 癒し |
| 真似した・ネタにして乗っかった | 草 |
| 信じた・学んだ・感心した | 神 |

- 属性は基本1つ。2つ目は明らかに別の反応もあるときだけ付ける
- 草は何でも入りやすいので、パックごとに草が主属性のカードは2割程度までにする
- 実在の人が傷つく話題（性別、障害、容姿など）は題材にしない

## 界隈（カードが何者かを表す。いわゆる種族）

属性（人がどう反応したか）とは別の軸。1枚に最大2つ。5つで始め、むやみに増やさない。

| 界隈 | 入るもの | 主な属性 |
|---|---|---|
| ミーム | 人ではないネタそのもの。コピペ、ネタ画像、流行りの言い回し、ネットのおもちゃ、ネタとして使われる動物（猫ミームなど） | 草 |
| アイドル | アイドル、推され系、ステージに立つ人 | メロい |
| 有識者 | 専門家、論客、雑学、ファクトチェック | 神 |
| 配信者 | ネットで発信する人全般。YouTuber、VTuber、ライバー、インフルエンサー、クリエイター、歌い手 | 炎上（ほかの属性も多い） |
| 動物 | 癒やしとして見られる動物。猫、犬、動物動画、ペット | 癒し |

- 相性はあくまで傾向。「炎上したアイドル」「メロい有識者」のような組み合わせも自由
- 実在の個人やグループを特定する界隈は作らない
- 界隈を使う効果の型：場の〈〇〇界隈〉1体につきコスト-1／〈〇〇界隈〉が3体以上で全員強化／〈〇〇界隈〉を山札から手札へ／同じ界隈の味方が倒されたとき発動
- 追加の候補：野次馬（匿名のネット民・まとめ民。炎上の「集団」や草のトークンの受け皿）

## 闇堕ち（属性ではなく仕組み）

- 闇堕ちを持つのは、強いメイン級のカードだけ
- 闇堕ちを持つアイコンは、一度倒されたとき（体力が 0 になったとき）、オワコンへ行く代わりに裏返り、闇堕ちの姿で場に残る（1回だけ）
- 表面に闇堕ちのマークを付ける。裏の姿は裏返るまで相手に見せない
- 裏の姿は表より明らかに強い（攻撃力・効果）。代わりに体力が低い、回復を受けない、などの危うさを持つ
- 癒しで表に戻せる。戻ったカードは、また倒されれば闇堕ちできる
- 裏返った面の枠は黒と紫
- 各属性に1枚ずつ置く：炎上 レン／メロい トップアイドル／癒し ナギ／草 伝説のコラ画像／神 専門家（裏は「陰謀論者」）

## レアリティ

- ★1〜★5 の5段階。★が多いほど珍しく、★5 が最高。段階は今後増やさない
- 特別版は段階を増やさず、イラスト違い・キラ違いなどの仕様違いで出す
- ★1〜★3 にも主力になるカードを入れる。★4・★5 は「派手で目立つ」寄り
- 闇堕ちを持つのは ★4・★5 が中心
- ★4・★5 の人物は、男女の数をそろえる（2026年10月時点の★5：男性 シロガネ・レン・伝説のコラ画像・ナギ／女性 ミナモ・トップアイドル・専門家・ヒバナ）
- ★5 は専用デザインを作り、一覧でも効果の文字を常に表示する

## 場とカードの置き場所

| 置き場所 | 内容 |
|---|---|
| 山札 | 25枚。同じカードは3枚まで |
| 手札 | 山札から引いたカード |
| 場 | アイコンを横一列に 5 体まで置ける。ベンチは無い（手札か場の2択） |
| オワコン | 倒されたアイコンや捨てたカードが行く場所（いわゆる墓地・トラッシュ） |

- トークン：カードとしてデッキには入っておらず、効果で場に生まれるアイコン（例：草）。オワコンに行くと消える

## 後攻の補正

- 後攻は手札が1枚多い状態で始まる
- 後攻の最初のターンだけ話題力 +1（次のターンからは通常どおり）
- 1試合が長くなりすぎないよう、マスターのライフ（今は 20）はカードを作り直したあと CPU 同士の対戦で調整する

## カードの種類

| 種類 | 役割 | ほかのゲームでいうと | 例 |
|---|---|---|---|
| アイコン | 場に出て戦う。攻撃力と体力を持つ | クリーチャー、フォロワー | 今あるカード |
| 投稿 | 使い切りの効果。使ったらオワコンへ | 呪文、スペル | 「晒し」「コミュニティノート」「引用」 |
| トレンド | 場全体に数ターン効き続け、お互いに影響する。場に出せるのは1枚だけで、新しいトレンドが出たら古いものは流れて消える | フィールドカード | 「#炎上中」「#癒し動画」 |

- トークン：効果で場に生まれるアイコン（例：草）
- まずアイコンと投稿で作り始め、トレンドは遊んでみてから足す

## デッキの組み方

- デッキに入れられる属性は2つまで（シャドウバースのクラス選びを2つに広げた形）。属性を持たない共通カードは、どのデッキにも入れられる
- デュエル・マスターズのような「マナの色で出せるカードが決まる」方式は採らない。話題力が毎ターン自動で増える仕組みと合わず、色が揃わない事故がライトな層の不満になりやすいため
- 2属性のカードは、その2つを選んだデッキにだけ入る
- 「自分の場に○○が N 体以上いれば」のような、同じ属性をそろえるほど得をする効果を少し混ぜる

## ガード

- 相手の場にガードがいる間は、ガードしか攻撃できない（ほかのアイコンにも、マスターにも攻撃できない）。ガードが味方への攻撃を全部受け止める
- ガードを攻撃すると、ガードの攻撃力の分だけ反撃のダメージを受ける（通常のアイコン同士の戦闘と同じ）
- 対抗手段：神の「訂正」でガードを消す、炎上の「晒し」で晒し者にしたアイコンはガードを無視して攻撃できる
- ガードを持つアイコンは攻撃力を低めにして、並べるだけで勝てないようにする
- 試合が長引きすぎないかは CPU 同士の対戦で確かめる
