# 用語集（ユビキタス言語）

カード・画面・ルール・SNS・会話で、同じものを同じ名前で呼ぶための辞書。**効果文・画面の文字・docs を書くときは、必ずここの呼び名を使う**。文の型は [card-text.md](card-text.md)。

コードでは `packages/cards/src/glossary.ts` が元になっている（解説の小窓の文・使わない呼び名の一覧）。効果文と画面の文字に、使わない呼び名が入っていると**テストで落ち、CI を通らない**（カード名の中と、コードのコメントは除く）。

## 考え方（10月24日）

オーナー：「別に投稿とかにこだわらない。アイコンって名前にもこだわらない。とにかくカードゲーム好きな人に伝わればいいと思う。そこに独自性がないから売れないってことはないはず」「代表的なカードゲームから、一番伝わる集約値的なのにしたい」

- 決まりの用語（カードの種類・置き場所・キーワード）は、**代表的なカードゲームでいちばん多く使われている言い方**にする。カードゲームを遊んだ人が、説明なしで分かるように
- 多数派が無いとき（ゲームごとに言い方がばらばら）は、**説明なしで意味が分かる普通の日本語**を選ぶ
- 独自の言葉は、**このゲームにしかない仕組み**（闇堕ち・バズ・注目・晒し）と、属性の「推し」だけに残す。世界観はカードの名前と絵で出す
- コードの名前（`icon`・`post`・`kaiwai`・`exposed` など）は変えない。下の表の「コード」の列で対応を取る

比べたゲーム：遊戯王 OCG、デュエル・マスターズ、ポケモンカード、ONE PIECE カードゲーム、マジック：ザ・ギャザリング（MTG）、Shadowverse、ハースストーン。

## 呼び名

### プレイヤーと数値

| 呼び名 | 意味 | 前の呼び名 | ほかのゲーム | コード |
|---|---|---|---|---|
| プレイヤー | 操作する人。相手のライフを 0 にすれば勝ち | マスター | プレイヤー（遊戯王・デュエマ・ポケカ・MTG）・リーダー（シャドバ・ワンピ）・ヒーロー（ハース） | `player`・`PlayerState` |
| ライフ | プレイヤーの体力。20 から始まる | ライフ | ライフ（MTG・ワンピ）・ライフポイント（遊戯王）・体力（シャドバ・ハース） | `lp` |
| コスト | カードを出す・使うための数。カードに書いた数と、ターンごとに増えて払う数の両方をコストと呼ぶ（「コスト 3/5」） | 話題力（払う数） | コスト（デュエマ・ワンピ・シャドバ・ハース）。払う数は マナ（MTG・デュエマ・ハース）・PP（シャドバ） | `cost`・`mana`・`maxMana` |
| 攻撃力 | 攻撃したとき・されたときに相手に与えるダメージ。赤で出す | 攻撃力 | 攻撃力（シャドバ・ハース・遊戯王）・パワー（MTG・デュエマ） | `attack` |
| 体力 | キャラクターの耐久。0 になったら破壊される。青で出す | 体力 | 体力（シャドバ・ハース）・HP（ポケカ） | `hp` |
| 強化 | 攻撃力・体力を上げること。一度上がったら、晒し状態と TL浄化でしか消えない（場の数を見て上がり下がりする効果は作らない）。強化中の数字は淡い金 | 強化 | バフ | `buff` |
| ★ | レアリティ。★1〜★5。★5 は切り札 | ★ | レアリティ | `rarity` |

- ★には名前を付けない（10月24日、オーナー：「なるべく名称は少ない方がいい」）。「★3」「★5」とだけ呼び、コモン・アンコモン・レアのような段階の名前は使わない
- 「マナ」は使わない（10月24日、オーナー）。払う数も「コスト」と呼ぶ。「話題力」は、ネットミームを看板にしないのでやめた

### カードの種類

| 呼び名 | 意味 | 前の呼び名 | ほかのゲーム | コード |
|---|---|---|---|---|
| キャラクター | 場に出して戦うカード | アイコン | キャラクター（ワンピ）・クリーチャー（MTG・デュエマ）・モンスター（遊戯王）・フォロワー（シャドバ）・ミニオン（ハース） | `icon` |
| 呪文 | 使い切りのカード。使ったら墓地へ | 投稿 | 呪文（デュエマ・ハース・MTG）・魔法（遊戯王）・スペル（シャドバ）・イベント（ワンピ） | `post` |
| トークン | 効果で生まれるカード（草・コピー・リスナーなどのキャラクターと、盾などの呪文）。キャラクターは破壊されるか手札に戻されると消え、呪文は使うと消える（墓地に行かない）。デッキには入れられない | トークン | トークン（MTG・シャドバ） | `token` |
| 草 | 効果で出るトークン。攻撃力1・体力1 | 草 | — | `t-kusa` |

- 場で戦うカードは、多数派の「クリーチャー」「モンスター」が人を指さないので、人を描くゲーム（ワンピース・ロルカナ）の「キャラクター」にした

### 属性と種族

| 呼び名 | 意味 | 前の呼び名 | ほかのゲーム | コード |
|---|---|---|---|---|
| 属性 | カードの勝ち方とデッキの決まりを決める分類。1 枚に 0〜1 個 | 属性 | 属性（遊戯王）・文明（デュエマ）・色（MTG・ワンピ）・タイプ（ポケカ）・クラス（シャドバ・ハース） | `attributes` |
| ニュートラル | 属性を持たないカード。どのデッキにも入れられる | 共通 | ニュートラル（シャドバ）・中立（ハース）・無色（MTG・ポケカ） | `attributes: []` |
| 種族 | そのカードが何者か（仲間の分類）。属性をまたいで付く。1 枚に 0〜2 個 | 界隈 | 種族（遊戯王・デュエマ・ハース）・タイプ（シャドバ）・特徴（ワンピ） | `kaiwai` |

属性（10月24日、オーナー：「属性は、炎、水、自然、神、メロいor推し」）：

| 属性 | 前の呼び名 | 色 | 今の勝ち方の癖 |
|---|---|---|---|
| 炎属性 | 炎上 | 朱色 | 晒し状態でガードと強化を剥がし、速攻・突進の手数で削る |
| 推し属性 | メロい | ピンク | 推しを育てて後半に押し切る。注目・強化・センター |
| 水属性 | 癒し | 水色 | 回復・眠り状態・ガードで粘り、回復するたびに強くなる |
| 自然属性 | 草 | 黄緑 | トークンで場を埋めて、数で押す |
| 神属性 | 神 | 金・白 | 引き続けて、確実に除去する |

- 王道の 5 つ（炎・水・自然・光・闇）のうち、闇は使わない。仕組みの「闇堕ち」とぶつかるため
- メロい（ピンク）に当たる王道の属性は無いので、このゲームの看板として「推し」にした（名詞でそろう・勝ち方が名前で分かる）
- 勝ち方の癖を、歴代のカードゲームの色の役割に合わせ直すかは、次の設計で決める（下の「これから決めること」）

種族の中身：ミーム種族・アイドル種族・配信者種族・有識者種族・動物種族。効果文では「ミーム種族1体につき」「有識者種族のカード」のように書く。

### キーワード（キャラクターの能力）

効果文の先頭に、この順で書く（[card-text.md](card-text.md)）。

| 呼び名 | 意味 | 前の呼び名 | ほかのゲーム |
|---|---|---|---|
| ガード | 相手は、ガードしか攻撃できない | ガード | 挑発（ハース）・守護（シャドバ）・ブロッカー（デュエマ、近い） |
| 速攻 | 場に出たターンに攻撃できる | 速攻 | 速攻（MTG）・突撃（ハース）・疾走（シャドバ）・スピードアタッカー（デュエマ） |
| 突進 | 場に出たターンに、相手のキャラクターにだけ攻撃できる | 凸 | 突進（シャドバ）・急襲（ハース） |
| 連撃 | 1 ターンに 2 回攻撃できる | 連撃 | 疾風（ハース） |
| 注目 | 自分のターンの始めに攻撃力+1。センターにいると+2。どの属性にも付けられる | 注目 | このゲームだけ（センターで得をする仕組み） |
| 便乗 | 自分か相手がバズを使うたび、攻撃力+1・体力+1 | — | このゲームだけ（バズに反応する。10月25日） |
| コンボ | 場に出たとき、このターンに先に出したほかのカード1枚につき攻撃力+1 | ノリ | コンボ（ハース） |

- 便乗は 10月25日に足した（オーナー：「推しには便乗って概念でいいのかもな？バズった曲に基本アイドルとかって乗るから」）。今は推し属性の歌い手・バーチャルアイドルだけが持つ
- 注目は、10月24日にいったん「成長」にしかけたが、オーナー：「5 個のバトル場の真ん中に出すと優遇があるという、このカードゲーム特有のルールの意味で注目でいい。全属性で注目は適用できる」で、注目のまま

### 状態（効果で付く・外れる）

効果文では「〇〇状態にする」と書き、中身は書かない（語を押すと解説の小窓が開く）。

| 呼び名 | 意味 | 前の呼び名 | ほかのゲーム | コード |
|---|---|---|---|---|
| 晒し状態 | ガードと、それまでの強化を失う。ずっと続く | 晒し・晒し者 | — | `exposed` |
| 眠り状態 | 次の自分のターン、攻撃できない | 眠り・眠らせる | ねむり（ポケカ）・凍結（ハース） | `asleep` |
| 沈黙状態 | キーワードと効果を失う | 訂正・訂正済み | 沈黙（ハース） | `silenced` |
| 無敵状態 | プレイヤーが、次の相手のターンが終わるまでダメージを受けない | 無敵 | — | `shieldUntil` |

### このゲームだけの仕組み

| 呼び名 | 意味 | コード |
|---|---|---|
| 闇堕ち | 闇堕ちを持つ★5が破壊されたら、次の自分のターンの始めに闇の姿で自動で場に戻ってくる | `dark` |
| 闇堕ちの姿 | 闇堕ちしたときの姿。破壊されたら消える | `dark` |
| バズ | 1 試合に 2 回、自分のキャラクター 1 体に攻撃力+2・体力+2と突進を付けるプレイヤーの技 | `buzz` |

- 進化は入れない（シャドバの丸写しになる。盤面を取り返す役目はバズ）
- 闇堕ちは残す。オーナー：「闇堕ちって全ての属性に+闇をつけるような感じだから、このゲームの有利な点でも不利な点でもある」。闇属性が無い分、多くのゲームが闇属性で出す「かっこいい系」を、闇堕ちの姿が担う

## 使わない呼び名

効果文と画面の文字に入っていると、テストで落ちる（`BANNED_TERMS`）。

| 使わない | 代わりに |
|---|---|
| アイコン・フォロワー・ミニオン | キャラクター |
| 投稿・スペル | 呪文 |
| オワコン・墓場・トラッシュ | 墓地（場所）・破壊（動き） |
| 倒す | 破壊する |
| マスター | プレイヤー |
| 話題力・マナ | コスト |
| 界隈 | 種族 |
| 凸 | 突進 |
| ノリ | コンボ |
| 訂正 | 沈黙状態 |
| 晒し者 | 晒し状態 |
| 眠らせる | 眠り状態にする |
| ドロー | カードを引く |
| 召喚 | 出す |
| 登場時 | 場に出たとき |
| 共通 | ニュートラル |
| 炎上・メロい・癒し・草属性 | 炎・推し・水・自然属性 |

カード名（「炎上商法」「凸待ち配信者」「訂正リプ」「ネタ投稿者」「#癒し動画」など）は世界観の固有名なので、そのまま使ってよい。

## 新しい語を足すとき

1. ここに呼び名・意味・前の呼び名・ほかのゲームでの言い方・コードの名前を足す（王道のゲームの言い方を調べてから決める）
2. `packages/cards/src/glossary.ts` の `TERMS` に、押したときの説明を足す（使わない呼び名ができたら `BANNED_TERMS` にも）
3. カードには名前だけを書く

`TERMS` に足した語がこのファイルに載っていないと、テストで落ちる。

## これから決めること

- **属性の勝ち方を、歴代のカードゲームの色の役割に合わせ直す**（10月24日、オーナー：「各属性の特徴も、歴代のカードゲームの特徴をまんま踏襲しよう」「推しだけはこのゲームの特徴としていくべきかも」）。カードの効果を属性の間で入れ替える大きな作り直しなので、設計メモと総当たりで別に進める
- **ゲームの名前**（オーナー：「トレンドカードとかにすると検索性能が下がる。ネットミームをタイトルに入れると、適切にネットミームと付き合う必要がある」）
