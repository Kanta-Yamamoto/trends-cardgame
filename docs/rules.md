# TRENDS ルール（v2）

数値は遊びながら調整する前提の仮決め。実装は `packages/game-core`。オンライン専用（ダメージの管理はアプリが行う）。

## 用語

| 用語 | 意味 |
|---|---|
| マスター | 操作するプレイヤー本人。相手のマスターを倒すのが目的 |
| ライフ | マスターの体力。20 から始まり、0 になったら負け |
| アイコン | 場に出して戦うカード（SNS のアイコン＝話題の人やネタ） |
| 攻撃力（赤） | 攻撃したとき・されたときに相手へ与えるダメージ。効果がない限り減らない |
| 体力（青） | アイコンの耐久。受けたダメージで減り、0 になったらトラッシュへ |
| 話題力 | アイコンを出すためのコスト |
| トラッシュ | 倒されたアイコンや捨てたカードが置かれる場所 |

## 勝ち方

- 相手のマスターのライフを 0 にする
- 相手がターン開始時に山札からカードを引けなかったら勝ち

## 準備

- ライフは 20 から始まる
- デッキは 20 枚。シャッフルして 4 枚引く（後攻は 5 枚）
- 先攻・後攻はランダム
- アイコンは場に 3 体まで

## ターンの流れ

1. **開始**：話題力の上限が 1 増え（最大 10）、全回復する。自分の場のアイコンが攻撃できるようになる
2. **ドロー**：1 枚引く。先攻の最初のターンは引かない
3. **メイン**：話題力を払ってアイコンを場に出す。場のアイコンで攻撃する（順番は自由）
4. **終了**：相手のターンへ

先攻の最初のターンの話題力は 1。後攻は最初のターンだけ話題力 +1（2 から始まる）。
先攻有利を和らげるため、後攻は「手札 +1 枚」と「最初のターンの話題力 +1」をもらう。

## 場に出す

- コスト分の話題力を払い、空いた枠に出す
- 出したターンは攻撃できない（速攻を除く）

## 攻撃

- 攻撃できるアイコン 1 体につき、1 ターンに 1 回
- 攻撃先は「相手のアイコン」か「相手のマスター」
- アイコン同士：お互いの攻撃力の分だけ、相手の体力にダメージを与える（同時）。体力が 0 以下になったアイコンはトラッシュへ
- 受けたダメージは次のターン以降も残る（回復しない）
- マスター：攻撃したアイコンの攻撃力の分、ライフが減る
- 相手の場に **ガード** がいる間は、相手のマスターを攻撃できない。相手のアイコンはガードを含めてどれでも攻撃できる

## キーワード

| キーワード | 効果 |
|---|---|
| 速攻 | 場に出たターンに攻撃できる |
| ガード | このアイコンがいる間、相手は自分のマスターを攻撃できない |
| 拡散 | 場に出たとき、カードを 1 枚引く |
| 炎上 | 場に出たとき、お互いのマスターに 2 ダメージ |
| 祝福 | 場に出たとき、自分のライフを 3 回復する（20 まで） |

## カード固有の効果

| アイコン | 効果 |
|---|---|
| シロガネ | ガード。場にある他の〈光輪〉アイコン 1 体につきコスト -1 |
| レン | 速攻。攻撃したとき、相手の手札をランダムに 1 枚捨てさせる |
| ミナモ | 場に出たとき、山札の上 3 枚から〈蒼空〉を 1 枚手札に加え、残りは山札の下へ |

## バランスの目安（v2）

CPU 同士で各 300 戦したときの結果（`planTurn` 同士）。

- ヘブン対インフェルノの勝率はほぼ五分（ヘブン 49%）
- 1 試合は平均 12〜15 ターン（両者合計）
- デッキ違いの対戦での先攻勝率は 54〜55%。インフェルノ同士だけ 64% と高め

## デモ用デッキ

- **ヘブン**（光輪・蒼空）：ガードと拡散で粘り、シロガネとミナモで押し返す
- **インフェルノ**（紅蓮）：速攻と炎上で早めに削り切る
