# TRENDS ルール（v10）

数値は遊びながら調整する前提の仮決め。実装は `packages/game-core`、設計の考え方は [design-v3.md](design-v3.md)、20 枚デッキ・バズ・自動の闇堕ちは [design-v10-buzz.md](design-v10-buzz.md)。オンライン専用（ダメージなどの管理はアプリが行う）。

## 用語

| 用語 | 意味 |
|---|---|
| マスター | 操作するプレイヤー本人。相手のマスターのライフを 0 にするのが目的 |
| ライフ | マスターの体力。20 から始まり、0 になったら負け |
| アイコン | 場に出して戦うカード（話題の人・動物・ネタ） |
| 投稿 | 使い切りのカード。効果を使ったらオワコンへ |
| 攻撃力（赤） | 攻撃したとき・されたときに相手へ与えるダメージ |
| 体力（青） | アイコンの耐久。受けたダメージで減り、0 になったらオワコンへ |
| 話題力 | カードを出す・使うためのコスト |
| 山札 | デッキ。ここからカードを引く |
| オワコン | 体力が 0 になったアイコンや使った投稿が置かれる場所（墓地）。効果で送るときは「オワコンにする」、送られることは「オワコンになる」と書く（「倒す」「破壊する」は使わない） |
| 属性 | 炎上・メロい・癒し・草・神。カードの戦い方の傾向とデッキの決まりを担う。1 枚に 0〜1 個（0 個は共通カード） |
| 共通カード | 属性を持たないカード。どのデッキにも入れられる |
| 界隈 | ミーム・アイドル・配信者・有識者・動物。カードの所属（誰と手を組むか）。属性をまたいで付く。1 枚に 0〜2 個（2 つ持つのは★3以上の少数） |
| トークン | 効果で生まれるアイコン（草など）。オワコンになると消える |
| 闇堕ち | 闇堕ちを持つ★5がオワコンになったあと、次の自分のターンの始めに闇の姿で自動で戻ってくること。コストなし。闇の姿がオワコンになったら消える |
| バズ | 1 試合に 2 回、自分のアイコン 1 体に攻撃力+2・体力+2と凸を付けるマスターの技 |

## 効果文の書き方（言い回しをそろえる）

同じ動きは、どのカードでも同じ言い回しで書く（10月20日にそろえた）。新しいカードもこれに合わせる。言葉はネットの世界観（オワコン・バズ・晒し・凸など）に寄せつつ、動きが一目で分かることを優先する。

| 動き | 書き方 | 使わない言い方 |
|---|---|---|
| 引く | カードを N 枚引く／さらにカードを 1 枚引く／（なければカードを 1 枚引く） | 1 枚引く（「カードを」を省く）・ドロー |
| トークンを出す | 草を N 体出す／自分の空いている枠すべてに草を出す | 生やす・呼ぶ・召喚 |
| ダメージ | 相手のアイコン 1 体に N ダメージ／相手のアイコンすべてに N ダメージ／相手のマスターに N ダメージ | — |
| 自動で選ぶ対象 | 攻撃力がいちばん高い相手のアイコン 1 体／コストがいちばん高い相手のアイコン 1 体（「1 体」を付ける） | 攻撃力がいちばん高い相手のアイコンに |
| オワコンにする | 相手のアイコン 1 体をオワコンにする／体力が N 以下の相手のアイコンすべてをオワコンにする／（きっかけ・結果は）オワコンになる | 倒す・倒される・破壊する・オワコンに送る・オワコンに行く |
| 回復 | 自分のライフを N 回復する／自分のアイコンすべてと自分のライフを N 回復する | アイコンすべてとライフを（「自分の」を省く） |
| 手札に戻す | 〜を持ち主の手札に戻す（トークンは消える） | 手札に戻す（持ち主・トークンの扱いを省く） |
| マスターに効果を付ける | 相手のマスターに「〜」効果を付与する（「〜」の中は、付けられたマスターから見た「自分の」で書く） | お告げ・予告など、効果ごとの新しい用語 |
| 範囲 | 自分の〜／相手の〜／自分のほかの〜 を必ず付ける | ほかのアイコンすべて（誰のか書かない） |
| 強化 | 攻撃力+N・体力+N | +N/+N（画面の数字の表示には使ってよい） |
| きっかけ | 場に出たとき／オワコンになったとき／凸で攻撃したとき／闇堕ちしたとき／自分のターンの終わりに | 登場時・破壊時・倒されたとき |
| 置き場所 | 場・手札・山札・オワコン | フィールド・デッキ（引く場所として）・墓地・トラッシュ |

## 勝ち方

- 相手のマスターのライフを 0 にする
- 相手がターンの始めに山札からカードを引けなかったら勝ち
- 相手が降参したら勝ち（降参は自分の番でなくてもできる）
- オンライン対戦で、相手が持ち時間を使い切ったら勝ち（持ち時間は 1 試合で 5 分。自分のターンのあいだ減る。1 ターンは 30 秒までで、過ぎたら自動でターンを終える。`packages/game-core/src/clock.ts`）

## 準備

- ライフは 20 から始まる
- デッキは 20 枚（同じカードは 2 枚まで。トークンは入れられない。属性は 1 つ＋共通カード。闇堕ちを持つカードは 1 種類まで）。山札をシャッフルして、先攻は 3 枚・後攻は 4 枚引く。手札は 9 枚まで。9 枚のときに引いたカードは、そのままオワコンへ（10月20日に 30 枚・3 枚まで → 20 枚・2 枚まで）
- デッキに入れられる属性は 1 つ（初期リリースは単属性だけ。10月19日に 2 つ→1 つ）。共通カードは属性に数えず、いくつでも入れられる（共通カードだけでもよい）
- 闇堕ちを持つカード（エース）は 1 種類まで（2 枚まで入れられる＝闇堕ちは最大 2 回）。★5 の種類は制限しない（闇堕ちのない★5 や『フィクサー』は何種類でも）
- 先攻・後攻はランダム
- 場は横一列に 5 枠。真ん中の枠は「センター」

## ターンの流れ

1. **開始**：話題力の上限が 1 増え（最大 10）、全回復する。自分の場のアイコンが攻撃できるようになる。注目を持つアイコンの攻撃力が伸びる
2. **ドロー**：1 枚引く。先攻の最初のターンは引かない
3. **メイン**：話題力を払ってアイコンを出す・投稿を使う。場のアイコンで攻撃する（順番は自由）
4. **終了**：相手のターンへ

先攻の最初のターンの話題力は 1。先攻有利を和らげるため、後攻は「手札 +1 枚（先攻 3 枚・後攻 4 枚）」と「最初のターンだけ話題力 +1」をもらう（10月19日に先攻 4・後攻 5 枚から減らした。CPU 総当たりで先攻の勝率 47%）。

## 出す・使う

- アイコン：コスト分の話題力を払い、空いた枠に出す。出したターンは攻撃できない（速攻を除く）
- 投稿：コスト分の話題力を払って使う。対象がある投稿は、相手か自分のアイコンを 1 体選ぶ

## 攻撃

- 攻撃できるアイコン 1 体につき、1 ターンに 1 回（連撃は 2 回）
- 攻撃先は「相手のアイコン」か「相手のマスター」
- アイコン同士：お互いの攻撃力の分だけ、相手の体力にダメージを与える（同時）。体力が 0 以下になったアイコンはオワコンへ
- 受けたダメージは次のターン以降も残る（回復の効果でだけ戻る）
- マスター：攻撃したアイコンの攻撃力の分、ライフが減る
- **ガード**：相手の場にガードがいる間は、ガードしか攻撃できない（ほかのアイコンもマスターも攻撃できない）。晒し者になったアイコンはガードを失う
- ガードへの対抗手段は、神の「訂正」（コミュニティノート）と炎上の「晒し」

## バズ

- マスターの技。**1 試合に 2 回**、自分のアイコン 1 体に **攻撃力+2・体力+2 と凸** を付ける。話題力は払わない
- 使えるのは自分の 4 ターン目から（後攻は 3 ターン目から）。1 ターンに 1 回まで
- 凸：出したばかりで攻撃できないアイコンも、そのターン相手のアイコンに攻撃できる（マスターは次のターンから）。もう攻撃できるアイコンにはステータスだけ
- 強化として扱う（晒し者になると消える。TL浄化でも消える）
- 使うと、画面の左右からマスターと「バズ」のカットインが入り（自分は左から・相手は右から）、対象のアイコンが盤面で光る。残りの回数はマスターの帯とバズのボタンに玉で出す
- 盤面を取り返すための手段を、どのデッキも凸のカードに頼らずに持てるようにするため（10月20日）

## 闇堕ち

- ★5 も、ほかのカードと同じく山札から引いて、手札から話題力を払って出す
- 闇堕ちを持つカードが元の姿でオワコンになったら、**闇の気配**が残る。**次の自分のターンの始めに、自動で**オワコンから「闇堕ちの姿」で場に出る。話題力は払わない。選ぶ操作はない（10月20日に「自分で選んでオワコンから出す」から変更）
- 出る枠はオワコンになった枠。埋まっていればほかの空き枠へ。空きが無ければ、空くまで待つ
- 回数の決まりはない。デッキに入れられる闇堕ちを持つカードは 1 種類・2 枚までなので、闇堕ちは最大 2 回（『フィクサー』で差し出せば早められる）
- 闇堕ちの姿は、出たターンから相手のアイコンに攻撃できる（凸。マスターは次の自分のターンから。速攻を持つ姿ならマスターも）。出たときに「闇堕ちしたとき」の効果が働く
- **闇堕ちの姿がオワコンになったら、そのカードは消える**（オワコンにも行かない）
- 癒しの「TL浄化」で闇堕ちを元の姿に戻せる。戻った姿は、オワコンになっても、もう闇堕ちしない。闇堕ちの姿のまま手札に戻されたカードも、次にオワコンになったときは闇堕ちしない
- 画面：闇の気配があると、持ち主の側から盤面が紫に染まり、オワコンになった枠に紫の炎が灯る（予兆）。闇堕ちの姿が場にいる間は、盤面全体が暗い闇のフィールドになる。闇堕ちするときは、両方のプレイヤーの画面に闇堕ちの演出が出る
- 闇堕ちの姿と「闇堕ちしたとき」の効果は、カード一覧でも対戦中でも、カードを大きく見ると確認できる。闇堕ち中は元の効果を失う
- 「闇堕ちしたとき」の効果は、属性の勝ち方に合わせてカードごとに違う（全体ダメージ・眠り・確定除去・手札に戻す・マスターを守る・奪う・草で埋める・蘇生 など）
- 闇堕ちを持つのは、炎上（レン・カグラ）・メロい（トップアイドル・ミレイ）・神（専門家）・草（伝説のコラ画像・クサハミ）・癒し（ナギ・ルリ）。基本は 6〜7 コスト（クサハミだけ 4 コスト。差し出して早く闇堕ちさせる型の例外）
- マスターを守る：次の相手のターンが終わるまで、マスターはダメージを受けない（攻撃も効果も防ぐ）

## キーワード

| キーワード | 効果 |
|---|---|
| 速攻 | 場に出たターンに攻撃できる |
| ガード | 相手は、このアイコン（とほかのガード）しか攻撃できない。無条件に相手に戦いを強いるので、持つカードは少なめ（9枚。★5はナギ・ヨミだけ）。各属性に 1 枚以上（「コストの階段」） |
| 連撃 | 1 ターンに 2 回攻撃できる |
| 凸 | 場に出たターンに、相手のアイコンにだけ攻撃できる（マスターは攻撃できない）。キーワード自体でステータスは上がらない。「凸で攻撃したとき、攻撃力+N・体力+N」の効果を持つカードは、上がった攻撃力で殴る（出たターンに相手のアイコンへ攻撃したときだけ） |
| 注目 | 自分のターンの始めに攻撃力 +1。センターにいると +2 |
| ノリ | 場に出たとき、このターンに出したほかのカード 1 枚につき攻撃力 +1 |

## 属性

| 属性 | 勝ち方の癖 | 弱いところ | 色 |
|---|---|---|---|
| 炎上 | 出る杭を燃やす。相手の頼りのアイコン（育てた推し・ガード）を晒してガードと強化を剥がし、速攻・凸の手数で削る。炎上商法で自分も燃えて一瞬強くなる | 息切れが早い・体力が低い | 朱色 |
| メロい | 推しを育てて後半に押し切る。注目・強化・センター | 育つ前は弱い。晒されると育てた分が消える | ピンク |
| 癒し | 回復・眠り・ガードで粘り、回復するたびに強くなる・相手にダメージを返す。回復の回数で大物が安くなる | 回復の仕組みがそろう前に押し切られると弱い | 水色 |
| 草 | トークンで場を埋めて、数で押す。一斉攻撃 | 1体ずつは弱い。体力1のアイコンをまとめてオワコンにされると崩れる | 黄緑 |
| 神 | 引き続けて、確実に除去する。ガードは少し | 守りを上回る攻撃力には押し切られる | 金・白 |

属性どうしの有利・不利を決める効果（「○○属性に強い」など）は無い。勝ち方の癖がぶつかった結果として、相性が生まれる（例：メロいが重ねた強化や癒しのガードは、炎上の晒しで剥がれる）。どのデッキでも、どの相手とも戦える範囲に収める。

「自分の場に○○が N 体以上いれば」という効果は、そのアイコン自身も数に入る。同じ属性をそろえるほど得をする。

## コストの階段（10月23日）

オーナーと決めた、★5 以外のカードの並べ方。属性ごとに、アイコンをコスト 1〜8 に 1 種類ずつ置き、効果を階段状に重くする。2〜4 コストだけは 2 種類ずつにして、序盤の選び方に幅を持たせる。投稿も、同じ属性の中で同じコストを 2 枚作らない（全部のコストは埋めない）。★5 はこの外（尖った切り札）。共通カードも同じ決まりにそろえ、属性のカードより少し弱くする（単属性が得をするように）。

| | 数値の上限（攻撃力＋体力） |
|---|---|
| 効果なし | コスト＋2（1 コスト 3、2 コスト 4、3 コスト 5 …） |
| 効果あり（キーワードも効果に数える） | コスト＋1（1 コスト 2、2 コスト 3、3 コスト 4 …）。強い効果なら、さらに下げる |
| 草のトークン・コピー | 1 体＝1 点で数える |

投稿の目安：2 コストで「2 ダメージ＋何か」、4 コストで 2 枚引く、5 コストで確定除去、8 コストで相手のアイコンすべてに 5 ダメージ。除去は属性ごとのやり方で 4〜5 コストに置く（神は確定除去、炎上はダメージを受けている相手、メロいは奪う、草は草にする、癒しは手札に戻す）。

## 除去の投稿

強化の投稿（ファンサ・生誕祭 など）に対して、相手のアイコンを片付ける投稿。属性ごとに片付け方が違う。

| 投稿 | 属性 | コスト | 片付け方 |
|---|---|---|---|
| 完全論破 | 神 | 5 | 相手のアイコン1体をオワコンにする（体力に関係なく） |
| 追い炎上 | 炎上 | 4 | ダメージを受けている相手のアイコン1体をオワコンにする（全体ダメージ・燃料投下と組む） |
| ブロック | 癒し | 4 | 相手のアイコン1体を持ち主の手札に戻す（トークンは消える。出し直しに話題力がかかる） |
| 引き抜き | メロい | 5 | 攻撃力3以下の相手のアイコン1体を奪う（奪ったターンは攻撃できない） |

## 界隈

属性が「どう勝つか」なら、界隈は「誰と手を組むか」。カードゲームの例えで言えば、属性は色、界隈は種族。決まりは [design-v6-kaiwai.md](design-v6-kaiwai.md)。

- 界隈は属性をまたいで付く（配信者は炎上にも癒しにもいる）。2 属性のデッキで、属性の違うカードどうしをつなぐ接着剤が界隈
- 界隈でデッキを縛らない。デッキの決まりは属性だけ
- 界隈を参照する効果は、自分の側だけ（数える・仲間を強める・引く・安くする）。相手の界隈を名指しする効果（「相手の配信者をオワコンにする」など）は作らない
- 2 つの界隈に入るカード（ミナモ＝配信者＋アイドル、猫ミーム＝ミーム＋動物 など）は、両方の仲間として数えられる。その分だけ強いので★3以上の少数に限る
- 対戦中のカードでは、属性の丸の横に黒い四角で界隈の頭の字（配・ア・有・動・ミ）を出す

界隈を読む効果（すべて自分の側だけを見る）：

| 効果 | 内容 | 持つカード |
|---|---|---|
| 1体につき | 自分の場のほかのその界隈のアイコン1体につき攻撃力+1（2つの界隈に入るカードは、どちらにも数える） | コラボ配信（配信者）、伝説のコラ画像（ミーム） |
| 仲間を強める | 自分のほかのその界隈のアイコンすべてを強化 | 敏腕プロデューサー（アイドル） |
| 探して引く | 山札からその界隈のカードを探して手札に（なければ普通に引く） | 検索ニキ（有識者） |
| いれば | 自分の場にその界隈がいれば、効果が増える | アイドル評論家（アイドル）、剥がし（アイドル） |

| 界隈 | 炎上 | メロい | 神 | 草 | 癒し |

## デッキ構築

「デッキ構築」画面で、カード一覧から足し引きして 20 枚のデッキを自由に組み、名前を付けてその端末に保存できる（ログイン不要。localStorage）。保存したデッキは CPU 対戦とオンライン対戦のデッキ選択に「自分のデッキ」として出る。オンライン対戦では、カードの並びを "custom:…" の形でサーバーに送り、サーバー側でも決まり（20 枚・2 枚まで・属性 1 つ＋共通・闇堕ちを持つカードは 1 種類）を確かめる。前に組んだ 30 枚のデッキや属性 2 つのデッキ、闇堕ちを持つカードを 2 種類以上入れたデッキは、デッキ選択に出ない（「デッキを組む」で直すと選べる）。

## CPU の考え方

- `planTurnSearch`（対戦で使う CPU）：1ターンの「出す・使う・攻撃」の並びをビームサーチでたくさん試し、有望な終わり方は「ターンを終えて相手が場のアイコンで殴り返す」ところまで試してから、盤面の点数（ライフ・場のアイコンの強さ・手札の枚数）が一番高いものを選ぶ。相手の手札・山札の中身は見ない。重さは候補 20・最大 8000 手・400 ミリ秒まで
- バズ：先読みでは「自分のアイコン 1 体にバズ」も候補に入れる。盤面の点数で、残っているバズ 1 回を 4 点と数えるので、それより得をする場面（オワコンにできなかった相手をオワコンにする・とどめ）でだけ使う。闇堕ちは自動なので選ばない
- `planTurn`（貪欲法）：採点ルールで一番点の高い手を順に選ぶ。探索の候補の1つと、相手の殴り返しの読みに使う。先読みする CPU はこれに約 8 割勝つ
