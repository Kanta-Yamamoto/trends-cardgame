# TRENDS ルール（v5）

数値は遊びながら調整する前提の仮決め。実装は `packages/game-core`、設計の考え方は [design-v3.md](design-v3.md)。オンライン専用（ダメージなどの管理はアプリが行う）。

## 用語

| 用語 | 意味 |
|---|---|
| マスター | 操作するプレイヤー本人。相手のマスターを倒すのが目的 |
| ライフ | マスターの体力。20 から始まり、0 になったら負け |
| アイコン | 場に出して戦うカード（話題の人・動物・ネタ） |
| 投稿 | 使い切りのカード。効果を使ったらオワコンへ |
| 攻撃力（赤） | 攻撃したとき・されたときに相手へ与えるダメージ |
| 体力（青） | アイコンの耐久。受けたダメージで減り、0 になったらオワコンへ |
| 話題力 | カードを出す・使うためのコスト |
| 山札 | デッキ。ここからカードを引く |
| オワコン | 倒されたアイコンや使った投稿が置かれる場所（墓地） |
| 属性 | 炎上・メロい・癒し・草・神。カードの戦い方の傾向とデッキの決まりを担う。1 枚に 0〜1 個（0 個は共通カード） |
| 共通カード | 属性を持たないカード。どのデッキにも入れられる |
| 界隈 | ミーム・アイドル・配信者・有識者・動物。カードの所属（誰と手を組むか）。属性をまたいで付く。1 枚に 0〜2 個（2 つ持つのは★3以上の少数） |
| トークン | 効果で生まれるアイコン（草など）。オワコンに行くと消える |
| 闇堕ち | 闇堕ちを持つ★5が、オワコンから闇の姿で戻ってくること。1枚につき1回、コストなし |

## 勝ち方

- 相手のマスターのライフを 0 にする
- 相手がターンの始めに山札からカードを引けなかったら勝ち
- 相手が降参したら勝ち（降参は自分の番でなくてもできる）

## 準備

- ライフは 20 から始まる
- デッキは 30 枚（同じカードは 3 枚まで。トークンは入れられない。属性は 1 つ＋共通カード）。山札をシャッフルして、先攻は 3 枚・後攻は 4 枚引く。手札は 9 枚まで。9 枚のときに引いたカードは、そのままオワコンへ
- デッキに入れられる属性は 1 つ（初期リリースは単属性だけ。10月19日に 2 つ→1 つ）。共通カードは属性に数えず、いくつでも入れられる（共通カードだけでもよい）
- 先攻・後攻はランダム
- 場は横一列に 5 枠。真ん中の枠は「センター」

## ターンの流れ

1. **開始**：話題力の上限が 1 増え（最大 10）、全回復する。自分の場のアイコンが攻撃できるようになる。注目を持つアイコンの攻撃力が伸びる
2. **ドロー**：1 枚引く。先攻の最初のターンは引かない
3. **メイン**：話題力を払ってアイコンを出す・投稿を使う。場のアイコンで攻撃する（順番は自由）
4. **終了**：相手のターンへ

先攻の最初のターンの話題力は 1。先攻有利を和らげるため、後攻は「手札 +1 枚（先攻 3 枚・後攻 4 枚）」と「最初のターンだけ話題力 +1」をもらう（10月19日に先攻 4・後攻 5 枚から減らした。CPU 総当たりで先攻の勝率 47%）。

## 出す・使う

- アイコン：コスト分の話題力を払い、空いた枠に出す。出したターンは攻撃できない（速攻を除く）
- 投稿：コスト分の話題力を払って使う。対象がある投稿は、相手か自分のアイコンを 1 体選ぶ

## 攻撃

- 攻撃できるアイコン 1 体につき、1 ターンに 1 回（連撃は 2 回）
- 攻撃先は「相手のアイコン」か「相手のマスター」
- アイコン同士：お互いの攻撃力の分だけ、相手の体力にダメージを与える（同時）。体力が 0 以下になったアイコンはオワコンへ
- 受けたダメージは次のターン以降も残る（回復の効果でだけ戻る）
- マスター：攻撃したアイコンの攻撃力の分、ライフが減る
- **ガード**：相手の場にガードがいる間は、ガードしか攻撃できない（ほかのアイコンもマスターも攻撃できない）。晒し者になったアイコンはガードを失う
- ガードへの対抗手段は、神の「訂正」（コミュニティノート・神絵師 シロガネ）と炎上の「晒し」

## 闇堕ち

- ★5 も、ほかのカードと同じく山札から引いて、手札から話題力を払って出す
- 闇堕ちを持つカードがオワコンに行ったら、自分のターンの好きなとき（倒されたそのターンのうちも）に、オワコンから「闇堕ちの姿」で場に出せる。話題力は払わない
- 1 枚につき **1 回だけ**。同じカードが 2 枚オワコンにあれば、それぞれ 1 回ずつ
- 闇堕ちの姿は、戻ってきたターンから相手のアイコンに攻撃できる（凸。マスターは次の自分のターンから。速攻を持つ姿ならマスターも）。出たときに「闇堕ちしたとき」の効果が働く。出したときの除去で盤面を返し、倒されたらもう一度オワコンから出てきて除去する、という使い方ができる
- 闇堕ちの姿と「闇堕ちしたとき」の効果は、カード一覧でも対戦中でも、カードを大きく見ると確認できる（オワコンから闇堕ちさせる画面にも出る）。闇堕ち中は元の効果を失う
- 闇堕ちの姿が倒されたら、そのカードの出番は終わり。癒しの「TL浄化」で相手の闇堕ちを元の姿に戻せるが、もう一度は闇堕ちしない
- 闇堕ちするときは、両方のプレイヤーの画面に闇堕ちの演出が出る
- 「闇堕ちしたとき」の効果は、属性の勝ち方に合わせてカードごとに違う（全体ダメージ・眠り・確定除去・手札に戻す・マスターを守る・味方の強化・奪う・草で埋める・蘇生 など）
- 手札に戻された闇堕ちの姿は、もう闇堕ちしない（1枚につき1回）
- マスターを守る：次の相手のターンが終わるまで、マスターはダメージを受けない（攻撃も効果も防ぐ）

## キーワード

| キーワード | 効果 |
|---|---|
| 速攻 | 場に出たターンに攻撃できる |
| ガード | 相手は、このアイコン（とほかのガード）しか攻撃できない。無条件に相手に戦いを強いるので、持つカードは少なめ（16枚。★5はナギ・ユズハ・ヨミだけ） |
| 連撃 | 1 ターンに 2 回攻撃できる |
| 凸 | 場に出たターンに、相手のアイコンにだけ攻撃できる（マスターは攻撃できない）。キーワード自体でステータスは上がらない。「凸で攻撃したとき、攻撃力+N・体力+N」の効果を持つカードは、上がった攻撃力で殴る（出たターンに相手のアイコンへ攻撃したときだけ） |
| 注目 | 自分のターンの始めに攻撃力 +1。センターにいると +2 |
| ノリ | 場に出たとき、このターンに出したほかのカード 1 枚につき攻撃力 +1 |

## 状態

| 状態 | 付ける効果 | 内容 |
|---|---|---|
| 晒し | 晒し・大炎上・燃料投下・野次馬・暴露系配信者・炎上中のアイドル・デジタルタトゥー・ヒバナ・炎上商法（炎上）、陰謀論者 | ガードを失い、それまでの強化（プラスの分）がすべて消える。ずっと続く（晒されたあとの強化は消えない）。相手の TL浄化で元に戻る |
| 眠り | 寝落ち配信・ASMR配信者・ナギ（癒し） | 次の自分のターン、攻撃できない |
| 訂正 | コミュニティノート（神）・堕天のシロガネ | キーワードと効果が消える（ガードも無くなる） |

## 属性

| 属性 | 勝ち方の癖 | 弱いところ | 色 |
|---|---|---|---|
| 炎上 | 出る杭を燃やす。相手の頼りのアイコン（育てた推し・ガード）を晒してガードと強化を剥がし、速攻・凸の手数で削る。炎上商法で自分も燃えて一瞬強くなる | 息切れが早い・体力が低い | 朱色 |
| メロい | 推しを育てて後半に押し切る。注目・強化・センター | 育つ前は弱い。晒されると育てた分が消える | ピンク |
| 癒し | 回復・眠り・ガードで粘り、回復するたびに強くなる・相手にダメージを返す。回復の回数で大物が安くなる | 回復の仕組みがそろう前に押し切られると弱い | 水色 |
| 草 | トークンで場を埋めて、数で押す。一斉攻撃 | 1体ずつは弱い。体力1をまとめて倒されると崩れる | 黄緑 |
| 神 | 引き続けて、確実に除去する。ガードは少し | 守りを上回る攻撃力には押し切られる | 金・白 |

属性どうしの有利・不利を決める効果（「○○属性に強い」など）は無い。勝ち方の癖がぶつかった結果として、相性が生まれる（例：メロいが重ねた強化や癒しのガードは、炎上の晒しで剥がれる）。どのデッキでも、どの相手とも戦える範囲に収める。

「自分の場に○○が N 体以上いれば」という効果は、そのアイコン自身も数に入る。同じ属性をそろえるほど得をする。

## 除去の投稿

強化の投稿（ファンサ・生誕祭 など）に対して、相手のアイコンを片付ける投稿。属性ごとに片付け方が違う。

| 投稿 | 属性 | コスト | 片付け方 |
|---|---|---|---|
| 完全論破 | 神 | 4 | 相手のアイコン1体を倒す（体力に関係なく） |
| 追い炎上 | 炎上 | 3 | ダメージを受けている相手のアイコン1体を倒す（全体ダメージ・燃料投下と組む） |
| ブロック | 癒し | 3 | 相手のアイコン1体を持ち主の手札に戻す（トークンは消える。出し直しに話題力がかかる） |
| 引き抜き | メロい | 4 | 攻撃力3以下の相手のアイコン1体を奪う（奪ったターンは攻撃できない） |
| 剥がし | メロい | 3 | 相手のアイコンすべてに1ダメージ。自分の場にアイドルがいれば、さらに1（並べた小さいアイコンを片付ける） |
| 大炎上・トレンド入り・訂正リプ | 炎上・共通・神 | 3・3・2 | ダメージ（3・3・2） |

草には除去の投稿が無い（数で押す属性なので、代わりに草を増やす投稿が多い）。

## 界隈

属性が「どう勝つか」なら、界隈は「誰と手を組むか」。カードゲームの例えで言えば、属性は色、界隈は種族。決まりは [design-v6-kaiwai.md](design-v6-kaiwai.md)。

- 界隈は属性をまたいで付く（配信者は炎上にも癒しにもいる）。2 属性のデッキで、属性の違うカードどうしをつなぐ接着剤が界隈
- 界隈でデッキを縛らない。デッキの決まりは属性だけ
- 界隈を参照する効果は、自分の側だけ（数える・仲間を強める・引く・安くする）。相手の界隈を名指しする効果（「相手の配信者を倒す」など）は作らない
- 2 つの界隈に入るカード（ミナモ＝配信者＋アイドル、猫ミーム＝ミーム＋動物 など）は、両方の仲間として数えられる。その分だけ強いので★3以上の少数に限る
- 対戦中のカードでは、属性の丸の横に黒い四角で界隈の頭の字（配・ア・有・動・ミ）を出す

界隈を読む効果（すべて自分の側だけを見る）：

| 効果 | 内容 | 持つカード |
|---|---|---|
| 1体につき | 自分の場のほかのその界隈のアイコン1体につき攻撃力+1（2つの界隈に入るカードは、どちらにも数える） | コラボ配信（配信者）、伝説のコラ画像（ミーム） |
| 仲間を強める | 自分のほかのその界隈のアイコンすべてを強化 | トップアイドル・敏腕プロデューサー（アイドル）、ミーム考古学者（ミーム）、同接感謝（配信者）、もふもふタイム（動物） |
| 探して引く | 山札からその界隈のカードを探して手札に（なければ普通に引く） | 引用リツイート（有識者） |
| いれば | 自分の場にその界隈がいれば、効果が増える | 切り抜き動画（配信者）、アイドル評論家（アイドル）、学会の重鎮（有識者3体） |
| 界隈に使う投稿 | 自分のその界隈のアイコンだけを対象にできる | 推しへのファンレター（アイドル） |
| 界隈ぶん燃やす | 自分の場のその界隈1体につき相手のマスターにダメージ | ミーム動画編集者（ミーム） |

| 界隈 | 炎上 | メロい | 神 | 草 | 癒し |
|---|---|---|---|---|---|
| 配信者 | 10 | 3 | 1 | 4 | 7 |
| ミーム | 4 | – | – | 12 | 1 |
| アイドル | 1 | 8 | – | 2 | 1 |
| 有識者 | 2 | 1 | 13 | 1 | 3 |
| 動物 | – | – | – | 2 | 7 |

## 切り札の仕組み（★4〜5・推し）

| 仕組み | 内容 | 持つカード |
|---|---|---|
| コストが下がる | 手札にある間、条件の分だけコストが下がる（0 より下にはならない） | ゆるキャラ（回復した回数） |
| 奪う | 相手のアイコンを自分の場に移す。奪ったターンは攻撃できない | ホスト系配信者 |
| 倒すたびにもう1回 | 相手のアイコンを倒すたび、攻撃回数が1回増える | レン |
| 子守唄 | 場にいる間、相手のターンの始めに相手の攻撃力がいちばん高いアイコンを眠らせる | ナギ |
| センターの輪 | センターにいる間、自分のほかのアイコンも注目と同じく攻撃力が伸びる | トップアイドル |
| 一斉攻撃 | 自分のアイコンすべてがすぐ攻撃できるようになり、そのターンはガードを無視できる | 伝説のコラ画像（ミーム女王は、すぐ攻撃できるだけ） |
| 一掃 | 体力が N 以下の相手のアイコンをすべて倒す | 論破王・大学教授（1 以下）、専門家・ヨミ（2 以下） |
| 回復するたびに | 自分が回復の効果を使うたびに働く（回復した量が0でも、効果を1つ使えば1回と数える） | 深夜ラジオのDJ（強くなる）、ユズハ（相手のマスターにダメージ）、ゆるキャラ（手札にある間、回復した回数だけコストが下がる） |
| ターンの終わり | 自分のターンの終わりに働く | シロガネ（1枚引く）、ミナモ（回復）、おひるねねこ（ライフ回復） |
| 蘇生 | オワコンから、コスト N 以下の自分のアイコン1体を場に戻す（いちばんコストが高いもの。同じなら、あとにオワコンになったもの）。戻ったカードの「場に出たとき」の効果も働く。戻ったターンは攻撃できない。空いた枠がなければ何も起きない | 不眠のルリ（3 以下） |
| 変身 | 相手のアイコンを草（1/1 のトークン）にする。元のカードはオワコンにも手札にも行かず消える | ネタにされる（投稿の対象）、黒歴史のララ（攻撃力がいちばん高い相手） |
| 場の数で引く | 自分の場のアイコン N 体につき 1 枚引く（トークンも数える。上限あり） | 伸びるリプ欄（2 体につき 1 枚、最大 3 枚） |
| 相手全体を弱める | 相手のアイコンすべての攻撃力を下げる（0 より下にはならない） | 病み期のミレイ（-2） |

## デッキ構築

「デッキ構築」画面で、カード一覧から足し引きして 30 枚のデッキを自由に組み、名前を付けてその端末に保存できる（ログイン不要。localStorage）。保存したデッキは CPU 対戦とオンライン対戦のデッキ選択に「自分のデッキ」として出る。オンライン対戦では、カードの並びを "custom:…" の形でサーバーに送り、サーバー側でも決まり（30 枚・3 枚まで・属性 1 つ＋共通）を確かめる。前に組んだ属性 2 つのデッキは、デッキ選択に出ない（「デッキを組む」で直すと選べる）。

## CPU の考え方

- `planTurnSearch`（対戦で使う CPU）：1ターンの「出す・使う・攻撃」の並びをビームサーチでたくさん試し、有望な終わり方は「ターンを終えて相手が場のアイコンで殴り返す」ところまで試してから、盤面の点数（ライフ・場のアイコンの強さ・手札の枚数）が一番高いものを選ぶ。相手の手札・山札の中身は見ない。重さは候補 20・最大 8000 手・400 ミリ秒まで
- `planTurn`（貪欲法）：採点ルールで一番点の高い手を順に選ぶ。探索の候補の1つと、相手の殴り返しの読みに使う。先読みする CPU はこれに約 8 割勝つ
