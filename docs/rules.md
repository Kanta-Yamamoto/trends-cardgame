# TRENDS ルール（v5）

数値は遊びながら調整する前提の仮決め。実装は `packages/game-core`、設計の考え方は [design-v3.md](design-v3.md)。オンライン専用（ダメージなどの管理はアプリが行う）。

## 用語

| 用語 | 意味 |
|---|---|
| マスター | 操作するプレイヤー本人。相手のマスターを倒すのが目的 |
| ライフ | マスターの体力。20 から始まり、0 になったら負け |
| アイコン | 場に出して戦うカード（話題の人・動物・ネタ） |
| 投稿 | 使い切りのカード。効果を使ったらオワコンへ |
| 攻撃力（赤） | 攻撃したとき・されたときに相手へ与えるダメージ |
| 体力（青） | アイコンの耐久。受けたダメージで減り、0 になったらオワコンへ |
| 話題力 | カードを出す・使うためのコスト |
| 山札 | デッキ。ここからカードを引く |
| オワコン | 倒されたアイコンや使った投稿が置かれる場所（墓地） |
| 属性 | 炎上・メロい・癒し・草・神。カードの戦い方の傾向。1 枚に 0〜2 個（0 個は共通カード） |
| 共通カード | 属性を持たないカード。どのデッキにも入れられる |
| 界隈 | ミーム・アイドル・配信者・有識者・動物。カードの所属。1 枚に 0〜2 個 |
| トークン | 効果で生まれるアイコン（草など）。オワコンに行くと消える |
| 推し | デッキの横の推し枠に置く★5。いつでも出せて、倒されたあと1回だけ闇堕ちして戻ってくる |
| 闇堕ち | 倒された推しが、闇の姿でオワコンから戻ってくること。1試合に1回 |

## 勝ち方

- 相手のマスターのライフを 0 にする
- 相手がターンの始めに山札からカードを引けなかったら勝ち
- 相手が降参したら勝ち（降参は自分の番でなくてもできる）

## 準備

- ライフは 20 から始まる
- デッキは 25 枚（同じカードは 3 枚まで。トークンと★5 は入れられない）＋推し枠に推し（★5）1 枚。山札をシャッフルして 4 枚引く
- デッキに入れられる属性は 2 つまで。共通カードは属性に数えず、いくつでも入れられる。2 属性のカードは、その 2 つを選んだデッキにだけ入る
- 先攻・後攻はランダム
- 場は横一列に 5 枠。真ん中の枠は「センター」

## ターンの流れ

1. **開始**：話題力の上限が 1 増え（最大 10）、全回復する。自分の場のアイコンが攻撃できるようになる。注目を持つアイコンの攻撃力が伸びる
2. **ドロー**：1 枚引く。先攻の最初のターンは引かない
3. **メイン**：話題力を払ってアイコンを出す・投稿を使う。場のアイコンで攻撃する（順番は自由）
4. **終了**：相手のターンへ

先攻の最初のターンの話題力は 1。先攻有利を和らげるため、後攻は「手札 +1 枚（5 枚で始める）」と「最初のターンだけ話題力 +1」をもらう。

## 出す・使う

- アイコン：コスト分の話題力を払い、空いた枠に出す。出したターンは攻撃できない（速攻を除く）
- 投稿：コスト分の話題力を払って使う。対象がある投稿は、相手か自分のアイコンを 1 体選ぶ

## 攻撃

- 攻撃できるアイコン 1 体につき、1 ターンに 1 回（連撃は 2 回）
- 攻撃先は「相手のアイコン」か「相手のマスター」
- アイコン同士：お互いの攻撃力の分だけ、相手の体力にダメージを与える（同時）。体力が 0 以下になったアイコンはオワコンへ
- 受けたダメージは次のターン以降も残る（回復の効果でだけ戻る）
- マスター：攻撃したアイコンの攻撃力の分、ライフが減る
- **ガード**：相手の場にガードがいる間は、ガードしか攻撃できない（ほかのアイコンもマスターも攻撃できない）。ただし晒し者になったアイコンはガードがいても攻撃できる
- ガードへの対抗手段は、神の「訂正」（コミュニティノート・神絵師 シロガネ）と炎上の「晒し」

## 推しと闇堕ち

- デッキの横の「推し枠」に、推し（★5）を 1 枚置く。★5 は推し枠専用で、山札には入れられない
- 推しは、話題力を払えばいつでも推し枠から場に出せる（1 回だけ）
- 推しが推し枠にいる間、自分のアイコンが倒されるたびに、推しのコストが 1 下がる（最低 3。押されているほど早く出せる）
- 推しが倒されたら、その次の自分のターンから **1 回だけ**、オワコンから「闇堕ちの姿」で出せる。話題力は払わない
- 闇堕ちの姿は、出たターンから攻撃できる（そのターンは相手のアイコンだけ）。出たときに「闇堕ちしたとき」の効果が働く
- 闇堕ちの姿は、闇堕ちするまで分からない（カード一覧では `/?dark` のときだけ見られる）。闇堕ち中は元の効果を失う
- 闇堕ちの姿が倒されたら、推しの出番は終わり。癒しの「TL浄化」で元の姿に戻せるが、もう一度は闇堕ちしない
- 闇堕ちするときは、両方のプレイヤーの画面に闇堕ちの演出が出る

## キーワード

| キーワード | 効果 |
|---|---|
| 速攻 | 場に出たターンに攻撃できる |
| ガード | 相手は、このアイコン（とほかのガード）しか攻撃できない |
| 連撃 | 1 ターンに 2 回攻撃できる |
| 叩き | ダメージを受けているアイコンを攻撃するとき、攻撃力 +2 |
| 注目 | 自分のターンの始めに攻撃力 +1。センターにいると +2 |
| ノリ | 場に出たとき、このターンに出したほかのカード 1 枚につき攻撃力 +1 |

## 状態

| 状態 | 付ける効果 | 内容 |
|---|---|---|
| 晒し | 晒し・大炎上・野次馬・暴露系配信者・ヒバナ（炎上） | 晒された時点で、強化（プラスの分）がすべて消える。相手の次のターンが終わるまで、ガードがいてもこのアイコンを攻撃できる |
| 眠り | 寝落ち配信・ASMR配信者・ナギ（癒し） | 次の自分のターン、攻撃できない |
| 訂正 | コミュニティノート（神）・堕天のシロガネ | キーワードと効果が消える（ガードも無くなる） |

## 属性

| 属性 | 勝ち方の癖 | 弱いところ | 色 |
|---|---|---|---|
| 炎上 | 序盤から殴り切る。速攻・連撃・叩き、晒しで強化を消す | 息切れが早い・体力が低い | 朱色 |
| メロい | 推しを育てて後半に押し切る。注目・強化・センター | 育つ前は弱い。晒されると育てた分が消える | ピンク |
| 癒し | 回復・眠り・ガードで粘り、回復するたびに強くなる・相手にダメージを返す。回復の回数で大物が安くなる | 回復の仕組みがそろう前に押し切られると弱い | 水色 |
| 草 | トークンで場を埋めて、数で押す。一斉攻撃 | 1体ずつは弱い。体力1をまとめて倒されると崩れる | 黄緑 |
| 神 | ガードで守りながら引き続け、確実に除去する | 守りを上回る攻撃力には押し切られる | 金・白 |

属性どうしの有利・不利を決める効果（「○○属性に強い」など）は無い。勝ち方の癖がぶつかった結果として、相性が生まれる（例：メロいが重ねた強化は、炎上の晒しで消える）。どのデッキでも、どの相手とも戦える範囲に収める。

「自分の場に○○が N 体以上いれば」という効果は、そのアイコン自身も数に入る。同じ属性をそろえるほど得をする。2 属性のカードは枠が斜めに 2 色に分かれる。

| ターンの終わり | 自分のターンの終わりに働く | シロガネ（1枚引く）、ミナモ（回復）、おひるねねこ（ライフ回復） |

## デモ用デッキ

- **大炎上で草**（炎上・草）：【推し：レン】速攻と連撃で早めに削る
- **推しに癒される**（メロい・癒し）：【推し：トップアイドル】注目で推しを育て、ガードと回復で守り切る
- **有識者の守り**（神・癒し）：【推し：ナギ】ガードで守りながら引き続け、除去で盤面を取る
- **論破で炎上**（炎上・神）：【推し：専門家】叩きと除去で相手のアイコンを減らし、押し切る
- **踊ってみたで草**（草・メロい）：【推し：伝説のコラ画像】草を増やして並べ、みんなで強くなる
- **推しが炎上**（炎上・メロい）：【推し：カグラ】速攻と強化で、推しが燃える前に押し込む
- **燃えても癒える**（炎上・癒し）：【推し：ユズハ】回復するたびに相手を燃やす（ユズハ）
- **草にマジレス**（神・草）：【推し：ヨミ】ネタを増やし、伝説のコラ画像で一斉に攻める
- **推しを考察**（神・メロい）：【推し：シロガネ】推しを守りながら、論破と強化で押し切る
- **ゆるいTL**（草・癒し）：【推し：ワラ】草を並べてガードで守り、数で押す

属性の組み合わせ 10 通りに 1 つずつ。自由にデッキを組めるようにするのは、この 10 個の調整が終わってから。

## CPU の考え方

- `planTurnSearch`（対戦で使う CPU）：1ターンの「出す・使う・攻撃」の並びをビームサーチでたくさん試し、有望な終わり方は「ターンを終えて相手が場のアイコンで殴り返す」ところまで試してから、盤面の点数（ライフ・場のアイコンの強さ・手札の枚数）が一番高いものを選ぶ。相手の手札・山札の中身は見ない。重さは候補 20・最大 8000 手・400 ミリ秒まで
- `planTurn`（貪欲法）：採点ルールで一番点の高い手を順に選ぶ。探索の候補の1つと、相手の殴り返しの読みに使う。先読みする CPU はこれに約 8 割勝つ
