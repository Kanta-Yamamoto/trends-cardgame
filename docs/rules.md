# TRENDS ルール（v1）

数値は遊びながら調整する前提の仮決め。実装は `packages/game-core`。

## 勝ち方

- 相手のフォロワー（ライフ）を 0 にする
- 相手がターン開始時に山札からカードを引けなかったら勝ち

## 準備

- フォロワーは 20000 から始まる
- デッキは 20 枚。シャッフルして 4 枚引く（後攻は 5 枚）
- 先攻・後攻はランダム
- 場には 3 枠まで出せる

## ターンの流れ

1. **開始**：話題力の上限が 1 増え（最大 10）、全回復する。自分の場のカードが攻撃できるようになる
2. **ドロー**：1 枚引く。先攻の最初のターンは引かない
3. **メイン**：話題力を払ってカードを場に出す。場のカードで攻撃する（順番は自由）
4. **終了**：相手のターンへ

先攻の最初のターンの話題力は 1。後攻は最初のターンだけ話題力 +1（2 から始まる）。

先攻有利を和らげるため、後攻は「手札 +1 枚」と「最初のターンの話題力 +1」をもらう。

## 場に出す

- コスト分の話題力を払い、空いた枠に出す
- 出したターンは攻撃できない（速攻を除く）

## 攻撃

- 攻撃できるカード 1 枚につき、1 ターンに 1 回
- 攻撃先は「相手のカード」か「相手本体」
  - 相手の場に **ガード** があるときは、ガードのカードを攻撃しないといけない
- カード同士：パワーが高い方が残り、低い方はトラッシュへ。同じなら両方トラッシュ
- 本体：攻撃したカードのパワー分、フォロワーが減る

## キーワード

| キーワード | 効果 |
|---|---|
| 速攻 | 場に出たターンに攻撃できる |
| ガード | 相手は、このカードから先に攻撃しないといけない |
| 拡散 | 場に出たとき、カードを 1 枚引く |
| 炎上 | 場に出たとき、お互いのフォロワーを 2000 減らす |
| 祝福 | 場に出たとき、自分のフォロワーを 2000 増やす（20000 まで） |

## カード固有の効果

| カード | 効果 |
|---|---|
| シロガネ | 場にある他の〈光輪〉1 枚につきコスト -1 |
| レン | 速攻。攻撃したとき、相手の手札をランダムに 1 枚捨てさせる |
| ミナモ | 場に出たとき、山札の上 3 枚から〈蒼空〉を 1 枚手札に加え、残りは山札の下へ |

## バランスの目安（v1）

CPU 同士で各 400 戦したときの結果（`planTurn` 同士）。

- ヘブン対インフェルノの勝率はほぼ五分（ヘブン 48%）
- 1 試合は平均 12〜13 ターン（両者合計）
- 先攻の勝率はまだ 60〜69% と高め。遊んで違和感があれば、後攻の補正を増やすか、先攻の最初のドローなしを維持したまま話題力の伸びを調整する

## デモ用デッキ

- **ヘブン**（光輪・蒼空）：ガードと拡散で粘り、シロガネとミナモで押し返す
- **インフェルノ**（紅蓮）：速攻と炎上で早めに削り切る
