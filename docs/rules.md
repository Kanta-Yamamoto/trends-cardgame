# TRENDS ルール（v3）

数値は遊びながら調整する前提の仮決め。実装は `packages/game-core`、設計の考え方は [design-v3.md](design-v3.md)。オンライン専用（ダメージなどの管理はアプリが行う）。

## 用語

| 用語 | 意味 |
|---|---|
| マスター | 操作するプレイヤー本人。相手のマスターを倒すのが目的 |
| ライフ | マスターの体力。20 から始まり、0 になったら負け |
| アイコン | 場に出して戦うカード（話題の人・動物・ネタ） |
| 投稿 | 使い切りのカード。効果を使ったらオワコンへ |
| 攻撃力（赤） | 攻撃したとき・されたときに相手へ与えるダメージ |
| 体力（青） | アイコンの耐久。受けたダメージで減り、0 になったらオワコンへ |
| 話題力 | カードを出す・使うためのコスト |
| 山札 | デッキ。ここからカードを引く |
| オワコン | 倒されたアイコンや使った投稿が置かれる場所（墓地） |
| 属性 | 炎上・メロい・癒し・草・神。カードの戦い方の傾向。1 枚に 1〜2 個 |
| 界隈 | ミーム・アイドル・配信者・有識者・動物。カードの所属。1 枚に 0〜2 個 |
| トークン | 効果で生まれるアイコン（草など）。オワコンに行くと消える |

## 勝ち方

- 相手のマスターのライフを 0 にする
- 相手がターンの始めに山札からカードを引けなかったら勝ち

## 準備

- ライフは 20 から始まる
- デッキは 25 枚（同じカードは 3 枚まで。トークンは入れられない）。シャッフルして 4 枚引く
- 先攻・後攻はランダム
- 場は横一列に 5 枠。真ん中の枠は「センター」

## ターンの流れ

1. **開始**：話題力の上限が 1 増え（最大 10）、全回復する。自分の場のアイコンが攻撃できるようになる。注目を持つアイコンの攻撃力が伸びる
2. **ドロー**：1 枚引く。先攻の最初のターンは引かない
3. **メイン**：話題力を払ってアイコンを出す・投稿を使う。場のアイコンで攻撃する（順番は自由）
4. **終了**：相手のターンへ

先攻の最初のターンの話題力は 1。先攻有利を和らげるため、後攻は「手札 +1 枚（5 枚で始める）」と「最初のターンだけ話題力 +1」をもらう。

## 出す・使う

- アイコン：コスト分の話題力を払い、空いた枠に出す。出したターンは攻撃できない（速攻を除く）
- 投稿：コスト分の話題力を払って使う。対象がある投稿は、相手か自分のアイコンを 1 体選ぶ

## 攻撃

- 攻撃できるアイコン 1 体につき、1 ターンに 1 回（連撃は 2 回）
- 攻撃先は「相手のアイコン」か「相手のマスター」
- アイコン同士：お互いの攻撃力の分だけ、相手の体力にダメージを与える（同時）。体力が 0 以下になったアイコンはオワコンへ
- 受けたダメージは次のターン以降も残る（回復の効果でだけ戻る）
- マスター：攻撃したアイコンの攻撃力の分、ライフが減る
- **ガード**：相手の場にガードがいる間は、ガードしか攻撃できない（ほかのアイコンもマスターも攻撃できない）。ただし晒し者になったアイコンはガードがいても攻撃できる
- ガードへの対抗手段は、神の「訂正」（コミュニティノート・神絵師 シロガネ）と炎上の「晒し」

## 闇堕ち

- 強いアイコン（★4〜5）の一部だけが持つ
- 初めて倒されたとき、オワコンに行かずに「闇堕ちの姿」に裏返って場に残る。ダメージと強化はリセットされる
- 闇堕ちの姿は裏返るまで分からない（カードには書いていない）。闇堕ち中は元の効果を失う
- 闇堕ちは 1 回だけ。闇堕ちの姿で倒されたらオワコンへ
- 癒しの「TL浄化」で元の姿に戻せる。戻ったアイコンは、もう一度闇堕ちできる
- 訂正されたアイコンは闇堕ちしない

## キーワード

| キーワード | 効果 |
|---|---|
| 速攻 | 場に出たターンに攻撃できる |
| ガード | 相手は、このアイコン（とほかのガード）しか攻撃できない |
| 連撃 | 1 ターンに 2 回攻撃できる |
| 叩き | ダメージを受けているアイコンを攻撃するとき、攻撃力 +2 |
| 注目 | 自分のターンの始めに攻撃力 +1。センターにいると +2 |
| ノリ | 場に出たとき、このターンに出したほかのカード 1 枚につき攻撃力 +1 |

## 状態

| 状態 | 付ける効果 | 内容 |
|---|---|---|
| 晒し | 晒し・大炎上（炎上） | 相手の次のターンが終わるまで、ガードがいてもこのアイコンを攻撃できる |
| 眠り | 寝落ち配信（癒し） | 次の自分のターン、攻撃できない |
| 訂正 | コミュニティノート（神） | キーワードと効果が消える（ガードも闇堕ちも無くなる） |

## 属性

| 属性 | 戦い方 | 色 |
|---|---|---|
| 炎上 | 集団で連続攻撃。連撃・叩き・晒し | 朱色 |
| メロい | 注目を集めて伸びる。センターで強い | ピンク |
| 癒し | 落ち着かせる。眠り・回復・ガード | 水色 |
| 草 | 便乗して増える。トークン・コピー・ノリ | 黄緑 |
| 神 | 正しさと知識。訂正・ドロー・確実な除去 | 金・白 |

属性どうしの有利・不利は無い。2 属性のカードは枠が斜めに 2 色に分かれる。

## デモ用デッキ

- **大炎上で草**（炎上・草）：速攻と連撃で早めに削り、草トークンで横に並べる
- **推しに癒される**（メロい・癒し）：ガードと回復で粘り、注目のアイドルを育てる
- **有識者の論破**（神・癒し）：ドローと訂正・除去で盤面を取ってから押し切る

## バランスの目安（v3）

CPU 同士（`planTurn` 同士）で全デッキの組み合わせを各 300 戦したときの結果。

- デッキ別の勝率：大炎上で草 53%、推しに癒される 50%、有識者の論破 47%
- 先攻の勝率 52%
- 1 試合は平均 14 ターン（両者合計）、長くて 28 ターン
