# カード面の基準：『演出家』（2026-10-22）

オーナー：「このカードかっこ良すぎるから、基準にしていこう」「似た感じでやっていく」。今後のカード面は、この『演出家』の作り方を基準にする。モック：claude.ai の Artifact「『演出家』カード面」。動画：広告用の短縮版 `director-card-ad.mp4`（6.6秒）、ループ版 `director-card-loop.mp4`（約13.5秒。古い秒数）。どちらも 720×1006・30fps。

**基準にするのは「二色・人物の切り抜き・レイアウト」まで。動きはカードごとに作る**（10月23日。オーナー：「なんでフィクサーのアニメーションが、演出家と同じやねん」「演出家をパクるな」）。斜線と回る幕は『演出家』だけのもの。

## 1. 考え方

- **二色だけ**：カードの地は「主色」と「黒」の2色だけ。グラデーション・模様・枠の飾りは使わない
- **境目が動く**：2色の境目が演出になる。文字は境目をまたぐと色が反転する。どう動くかはカードごとに決める
- **ふだんは止まっている**：ずっと動かさない。ときどきだけ演出が入る
- **人物は切り抜き**：元の絵の背景は捨て、人物だけを二色の地に置く。半身を隠さない（オーナー：「そもそも半身隠すのやめる」）

## 2. 色

| 役割 | 『演出家』の値 | 決め方 |
|---|---|---|
| 主色 | 真紅 `#cf1b10` | 元の絵の背景色をそのまま使う（スポイトで取る） |
| 黒 | `#1c171c` | 純黒ではなく、人物の服の黒に合わせる。黒の側で服が地に溶け、「黒になり切らない部分」が出ない |
| 攻撃力・体力 | 赤 `#ff4057`・青 `#3d8bff` | ゲームの決まりどおり。ここだけ二色の外の色 |

- 文字の色：主色の上では黒、黒の上では主色（反転）
- 調べたこと：肌色・白・銀・墨・群青・金も試したが、黒がいちばん良かった（オーナー）。群青は赤との境目で文字がちらつく

## 3. レイアウト（カードの幅を 100 としたときの大きさ。cqw）

| 場所 | 中身 | 書体・大きさ |
|---|---|---|
| 左上 | コスト（枠なしの数字だけ） | Lilita One・12 |
| 右上 | ★ | 4 |
| 下・名前 | 『名前』＋英語名（字間を広く。例：DIRECTOR） | 名前＝Zen Old Mincho 900・10.5／英語名＝Lilita One・3.2・字間 0.5em |
| 名前の下 | 細い線（文字と同じ色） | 太さ 0.4 |
| 効果文 | 太めのゴシック | M PLUS 1 800・3.25・行間 1.65 |
| いちばん下 | 左に「ICON · 共通」、右に攻撃力・体力の四角 | Lilita One 3・字間 0.35em／数字 7 |

- 左右の余白 6、下の余白 5.5
- 効果欄に箱（背景の板）は付けない。文字は地の上に直接置く
- 肩書き（「〜の」）は付けない。名前は『』付きの役職名だけ（『フィクサー』『調停者』『演出家』）
- 名前が長くて英語名とあわせて1行に収まらないときは、名前と英語名の字間・大きさを少し詰める（『フィクサー』：名前 8.8・英語名の字間 0.38em）
- フレーバーテキストは付けない

## 4. 人物

- 元の絵から切り抜く（`tools/cutout.py`、rembg の isnet-anime）
- 置き方：幅 96%、上寄せ（位置 50% 4%）。カードより縦長の絵でも頭が切れない
- 下のほうは文字の帯に向かってぼかして地に溶かす（56% から 74% にかけて透明に）。まっすぐ水平に切るのは不可（オーナー：「水平に切るの違和感ある」）
- 人物は境目の動きの影響を受けない（色が変わるのは地と文字だけ）

## 5. 『演出家』の動き（『演出家』だけのもの）

### ふだん

- 斜線（右上がり）が顔の高さで止まった二色。線より上が主色、下が黒
- 一色のまま長く止めるのは不可（オーナー：「一色を長くするのはなし」）

### 流れ（1周 約7.1秒。最後と最初がつながる）

カード面・バトル場の登場演出・動画のすべてでこの秒数を使う（オーナー：「この秒数がいい感じ」のあと、「止まったあと下まで行く時のスピードが速すぎるし、一定なのがダサい」「あいだでの停止を1秒短くしよう」で調整）。

| 順 | 場面 | 長さ | 速さの付け方 |
|---|---|---|---|
| 0 | 登場（確定演出）：黒い地に斜線が上から降りてきて、顔の高さで止まる | 1.5秒 | 最初は速く、最後はぐっとゆっくり（ease-out の 5 乗） |
| 1 | 止まる（二色） | 2秒 | — |
| 2 | 斜線が降り切って全面が主色 | 1.2秒 | ゆっくり動き出し、だんだん加速（ease-in の 3 乗）。一定の速さは不可 |
| 3 | 全面が主色 | 0.15秒 | — |
| 4 | 幕：上の一点を軸に、左右の黒い幕のふちが円を描くように回り、細い光の筋（円錐）になる | 0.6秒 | そこそこ速く（ease-out の 2 乗） |
| 5 | 細い光の筋が回って閉じ切り、全面が黒 | 1.15秒 | ゆっくり（ease-in-out） |
| 6 | 斜線が上から降りてきて、顔の高さで止まる（0 と同じ）→ 1 へ | 1.5秒 | 最初は速く、最後はゆっくり |

- 広告用の短縮版の動画は、黒 → 0〜5 → 黒（6.6秒。最初の黒につながる）
- バトル場の登場演出（`apps/web/src/game/DirectorField.tsx`）は 0〜5 を1回だけ流して消える。『演出家』が着地した瞬間に始まり、**着地の 0.4 秒後に**エースが舞台に上がる（10月23日。オーナー：「彼が出たあとに0.4秒ほどたってから、闇落ちキャラの召喚をするように」）
- 斜線：右上がり。左右の高さの差はカードの高さの 30%。止まる高さは中央で 42%
- 幕の軸：カード中央の少し上（x 50%・y −8%）。いちばん細い光の筋は、下端で幅 22%（半角 約 5.8°）
- 動きを減らす設定（prefers-reduced-motion）では動かさず、ふだんの二色で止める
- 速さの付け方の考え方：止まるところは「速く入って、最後はゆっくり」、止まっていたものが動き出すところは「ゆっくり動き出して、加速」

### やってはいけない（オーナーの指示）

- 右半分だけの幕（「ダサいから絶対やめて」）
- 時計の針のように回る線
- 幕を真横にまっすぐ寄せる（幕は斜め必須。上を軸にした円運動で閉じる）
- 急に閉める・急に止める（最後はゆっくり）
- 一定の速さで動かす
- ずっと動き続ける
- ほかのカードに斜線と回る幕を流用する（『演出家』だけのもの）

## 6. 作り方（実装のメモ）

- 二色のカード面は共通の部品：`apps/web/src/cards/faces/Duotone.tsx`（`DuotoneFace`。英語名と動き `DuoMotion` を渡す）と `cards/duotone.css`。カードごとに決めるのは CSS 変数の `--duo-main`（主色）・`--duo-base`（地の色）・`--subject`（切り抜き）と、動き。`FACES`（`HoloCard.tsx`）に `s-<名前>` のクラスで登録する
- 層：地 → 主色の層 → 人物 → 文字（主色）→ 文字（地の色）
- 主色の層と反転の文字の層に、同じ塗り方を毎フレーム当てる。形で切るなら `clip-path`（『演出家』。`cards/directorMotion.ts`）、ぼかした濃さなら `mask-image`（『フィクサー』。`cards/inkBleed.ts`）
- 手札・場の小さいカードとデッキ選択は `cN-art.jpg` を使うので、ふだんの姿（二色の地に切り抜き）の絵に差し替える。同じ名前で差し替えたら `sw.js` の `VERSION` を上げる
- 拡大表示だけが動き、一覧などでは止まった姿

## 7. ほかのカードに広げるとき

- 主色＝そのカードの元の絵の背景色、黒＝人物の服や影の黒に合わせる
- 絵を描くときは、背景を単色にしておく（切り抜きやすく、主色を取りやすい）
- 名前・効果・数値の並びは同じにして、色と絵を変える
- **動きはそのカード自身から作る**。案を複数、動くモックで見せてから選んでもらう
- テーマの色が黒のカードは、黒を主色に、元の絵の背景色を地の色にする（下の『フィクサー』）

## 8. 広げたカード

### 『フィクサー』（10月23日）

- 主色＝テーマの黒 `#0e0d0c`（服の黒）、地＝元の絵の背景の白 `#f2f1ee`。英語名 FIXER。切り抜きは全身（右半分のグリッチもそのまま残す）
- 決まるまで：最初は『演出家』の斜線と幕を流用して叱られた。白から黒へ変わる 6 案（糸・グリッチ・墨のにじみ・モザイク・電源が落ちる・黒塗り）を Artifact「『フィクサー』白から黒へ 6案」で見せ、「白が滲んで黒になる」に決定（オーナー：「ゆっくり白が、滲んで黒になってく感じとか？」「にじむやつを採用で。でも黒ににじんだらもう戻らなくていい」）
- ふだん：白い地に全身。一覧・手札・場の小さいカードもこの姿
- 拡大表示：紙に墨が染みこむように、ふちから黒がゆっくり滲み、細い筋を伸ばしながら内側へ広がって、最後に顔のあたりまで染まって全面が黒になる。3.4 秒（ゆっくり始まり、中ほどで少し速く、最後はゆっくり）。黒になったら止まり、戻らない
- 境目は硬い線にしない。ぼかした濃さで描くので、変わる途中は白と黒の間の灰色が出る（二色の決まりの例外。オーナーが選んだ）
- バトル場（`game/FixerField.tsx`。オーナー：「フィールド展開時も、同じように滲んで黒のまま。自分のターン終了時とかに滲んで戻る」）：盤面のふちから黒が滲んで全面が黒になる（2.2 秒）→ 名前が浮かび、場のアイコンすべてに上から白い糸が垂れる → 差し出しが決まると、選ばれたアイコンが糸で上へ引き抜かれ、ほかの糸は上へ戻る → 黒のまま残り、次のターンが始まったら黒が滲んで引いていく（2.2 秒）

### 『調停者』のバトル場（10月23日。カード面はまだ専用の紺・群青・白のまま）

- 青のフィールド（`game/ArbiterField.tsx`）：絵と同じ二色。夜の紺 `#091e4b` の地に、群青 `#1f3cff` の帯が右下がりに走る。帯は左上から降りてきて相手の場と自分の場の間で止まり（ease-out の 5 乗）、刃を振るい終えたら加速しながら右下へ抜ける（ease-in の 3 乗）
- 刃：最初の版（光の細い刃を左上から突き下ろす）は却下（「突き刺す方向意味わかんない」「ダサい釘みたいのやめろ、事前に見せろ」「閃光みたいなのでいい。それかしっかりした剣」）。『調停者』から対象へ放つ「突き」に決まり、今の形は [attack-motion-standard.md](attack-motion-standard.md)
