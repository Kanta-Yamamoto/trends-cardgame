# やることリスト

あとで手を付けるタスクを置く場所。「今すぐやる」ではなく、「こういうタスクがある」を忘れないためのもの。終わったら消す（経緯は [history.md](history.md) に書く）。

「」の中は受け取った言葉のまま。「読み」は Claude の解釈で、決定ではない。手を付ける前に確かめる。

### 対戦の画面

- [ ] 「闇落ちの毎回の確認UIは短くしてOK (キーワードにまとめる)」

  - 読み：ヒバナ（c4）の「相手のキャラクターを破壊するたび、相手のプレイヤーに1ダメージ」が、対戦中に見えなかった
- [ ] 「あなたのプレイヤーのエリアの中に重要な情報が入りすぎている」
- [ ] 「横持ちも検討」
  - 今の決まり（10月22日）は「画面はスマホの縦の形 1 つだけ」なので、やるならこの決まりを変えるかオーナーが決める（[working-agreement.md](working-agreement.md)）

### ガチャ

- [ ] 「１パックの強調表示修正」
  - 読み：ガチャの画面の「1 パック」のボタンの強調。要確認
- [ ] 「もっと5を煽ろう」
  - 読み：★5 が出るかもしれない期待を、もっと高める。場所（ガチャの画面・開ける演出など）は要確認

### カードの絵

- [ ] 「レアリティが低いやつはそもそも上のみの絵にする」
  - 読み：★が低いカードは、上半身など上の部分だけの絵にする。絵の注文の型（[card-art-prompt.md](card-art-prompt.md)）にも関わる

### 確認

- [ ] 「クサハミなど遠酒家で出てくると色が変わらないか確認」
  - 読み：「遠酒家」は『演出家』のこと。『演出家』で出たキャラクターは【場に出たとき】が働かないので、そのときの色（見た目）が正しいかを確かめる
