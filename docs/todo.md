# やることリスト

あとで手を付けるタスクを置く場所。「今すぐやる」ではなく、「こういうタスクがある」を忘れないためのもの。終わったら消す（経緯は [history.md](history.md) に書く）。

「」の中は受け取った言葉のまま。「読み」は Claude の解釈で、決定ではない。手を付ける前に確かめる。

## バトル画面のプレイヤーの見せ方（11月2日）

友人のフィードバックをオーナーが受けて。直す前に、アーティファクトで案を 3 つほど出す。

- [ ] 「このゲームのルールって、マスターみたいなプレイヤーに攻撃して、そいつを倒したら勝ちなんだよねっていう確認を何回もされた」
  - 読み：プレイヤーがアイコンも無く画面の真ん中の上に小さくあるので、キャラクターどうしの殴り合いで勝敗が決まると思われる
- [ ] 「マナーが見にくい」「バズは何回なのかもわからん」
  - 読み：「マナー」はコストのこと。ちいさい数字にまとめているコストとバズの回数を、見て分かるようにする
- [ ] 「あれもうまいこといくなら枠残さないでぎっちり詰め込んだ上で、召喚してるフィールドを大きく見せてもいい」
  - 読み：手札を拡大するために空けている枠をなくして、場を大きくする。画面を無駄なく使う
- [ ] オーナーの案：ユーザーアイコンを登録のときに 1 つ付ける・デフォルトで入れておき、そのアイコンを殴る。周りにバズのボタン・残りの回数・コストが増えたことが分かる見せ方を置く
- [ ] 案 A を軸に詰める（11月1日に決定。モックは Artifact「バトル画面の案」）
  - オーナー：「目線の真ん中が、VS になりそうな、いわゆる戦いの場所の中心点になる」
  - オーナー：「カードが重なるっていう表現は、できるだけ避けたい」「B 案で出してくれたみたいな縦長のやつで、綺麗に詰める」
  - オーナー：お互いのライフ・コスト・バズの表現は案 A のままでよい
  - オーナー：真ん中に VS・線引き・色で、自分と相手の陣地が分かれていることを見せる
  - 手札の詳細は「下半分でめくる」に決定（11月1日。オーナー：「一旦だからそれにしよう」）。手札を押すか「手札を見る」のボタンで開き、左右のスワイプで切り替え、閉じると盤面に戻る
  - オーナー：「出すで一発で決まらない。必ずその次に何か確認が出る」。キャラクターは出す場所、呪文は対象を、「出す」のあとに選び、「戻る」で引き返せる。対象のない呪文も確認を挟む
  - オーナー：場のカードに名前は出さない（「ここから得れる情報は何もない」）。攻撃力・体力の丸は、カードの縁との間隔をそろえ、丸どうしや札と重ねない
  - オーナー：名前の分は状態異常や、破壊されたときの能力を持っていることの表示に使う。カードの長さは今の 5 分の 4 くらいにして、余った場所に別の情報を置くか余裕を持たせる
  - 場のカードは、札をカードの中に入れる形に決定（11月2日。オーナー：「場のカードは、2 でお願いします」）
  - オーナー：真ん中の文字欄は、奥（相手側）に相手の行動の結果や状態、手前（自分側）に自分の効果の結果や「〜を選択してください」などの次の指示を出す。「これが一番デザインとして綺麗」
  - 次：残りの差分を見ながらオーナーが少しずつ指摘する
  - 読み：手札は 9 枚まで持てる（`MAX_HAND`）。6 枚以上で重ねずに並べる形は、まだ決まっていない

## アプリの音のフィードバック（11月2日）

オーナーが iPhone のアプリで触って：

- [ ] 「アプリを途中で閉じたりすると確定の音が聞こえなくなります」
- [ ] 「最初は音を聞こえなくするとか、そういう工夫をしていたら、そういうの全部なしでいい」「携帯の設定として音を出すんだったら出しっぱなしにする。出さないんだったら出さない」「最初から音を出す」
- [ ] 「iPhone の基準の音よりもだいぶ基準の音がでかすぎる」「普通の音にしといてほしい」
- [ ] 「音を出したまま、そのアプリを間違えて閉じたり開いたりしようとすると、異音がします」
- [ ] 「チュートリアルのところでも、音楽が鳴ってないので、ここはホームの画面の音が鳴っていてほしい」
- [ ] 「フィクサーの、効果で、体型が黒くなるときに…めちゃくちゃ邪見るというか、処理が重くて、背景の色がうまいこと言ってないみたいな感じの、ちらつき」（読み：盤面が黒くなる演出が iPhone で、黒から紫へきれいに移らず、ちらつく）
- [ ] 「一回コンピューターの対戦のときに、勝手に試合が落ちちゃいました」「正確にはホームではなく CPU 対戦の画面に戻りました」
  - 読み：アプリは残ったままページが読み直された。iOS がページの処理を止めた（メモリなど）と見ている。Build 4 から、落ちた対戦の記録が client の頭 crash- で届くので、最後の手を見る
  - 落ちた対戦に戻れる仕組み（対戦の状態を端末に残す）は、原因が分かってから決める
- [ ] カード面の『フィクサー』（faces/Fixer.tsx）も同じマスクの作りなので、iPhone でちらつくなら `paintBleed` に替える
- [ ] 公開の前に、`GET /logs/cpu-games` を守る（招待の守りの内側にある前提だが、アプリの出どころを名乗れば読める）
- [ ] 「草はみが闇落ちしたときに闇落ちの BGM が鳴りません」「星5問わずか闇落ちしたときに確定に BGM が変更になるかどうかを確認して」
- [ ] 「スクロールができない」（アプリの設定で止めていた。Build 4 で直る）
- [ ] 「スマホがめちゃくちゃ今熱くなってます」（ホームの背景の動きを止めた。Build 4 で確かめる）
