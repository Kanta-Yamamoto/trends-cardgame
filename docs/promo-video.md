# SNS に出すカードの動画

X などに出す、カード 1 枚を傾けて光らせる短い動画を作る道具。10月30日、オーナーが X のアカウントを作り「バズるまで地道に、視覚重視で投稿していく」ことにしたので作った（[history.md](history.md)「10月30日：SNS に出すカードの動画を作る道具」）。

## 撮り方

```sh
pnpm dev                       # web を立ち上げておく（撮影用のページを開くため）
pnpm promo:video c17 8.1       # 『演出家』を 8.1 秒撮る → sns/c17.mp4
pnpm promo:video c15           # 秒数を省くと 8 秒
pnpm promo:video c1 8 dark     # 闇堕ちの姿で撮る → sns/c1-dark.mp4
```

- 書き出しは縦長 4:5（1080×1350）・60fps の mp4（H.264）。X のタイムラインで大きく出る形
- 傾きは正面から始まって正面で終わる 8 の字。X で繰り返し再生されても、つなぎ目が出ない
- 書き出し先の `sns/` は git に入れない
- 撮るのは手元の Chrome（Playwright の `channel: "chrome"`）。ffmpeg は初めて撮るときに取りに行く（CI・Docker では落とさない）
- 1 秒分を撮るのに 30〜40 秒ほどかかる。いくつかを同時に撮ると、メモリの少ない Mac では撮影が時間切れになることがある

## 仕組み

- 撮影用のページ `apps/web/promo.html`（`src/promo/`）が、`?card=ID` のカードを 1 枚だけ、濃い青の地の真ん中に出す。本番のビルドには入らない
- 1 コマずつ止めて撮り、つないで動画にする。1 コマ撮るのに時間がかかっても、カード面の動きが先へ進まないよう、ページの時計を止めてから 1 コマ分ずつ進める
  - JS で時間を測って動くもの（『演出家』『フィクサー』の境目など。`performance.now`・`requestAnimationFrame`）は、Playwright の時計（`page.clock`）で止めて進める
  - CSS の動き（ミナモの泡・『調停者』の一太刀など）は、Web Animations の `currentTime` で同じ幅だけ進める
  - カードが出た瞬間から撮るので、出たときの動き（降りてくる・滲む・合わさる）から一連で映る
- 秒数は、カード面の動きの一周に合わせる。『演出家』は出てから一周して降り直すまでが 8.1 秒（`directorMotion.ts` の筋書き：降りる 1.5 秒 ＋ 繰り返しの 6.6 秒）

## 撮ったもの

| カード | 秒数 | 映っている動き |
|---|---|---|
| ミナモ（c3） | 8 | 泡が上がりながら傾いて光る |
| 『調停者』（c16） | 8 | ずれた上下が合わさり、一太刀の光と破片が消える |
| 『フィクサー』（c15） | 8 | 白い地に、ふちから黒が滲んで全面が黒になる |
| 『演出家』（c17） | 8.1 | 斜線が降りて止まる → 降り切って全面が赤 → 幕が光の筋に閉じて黒 → また降りる |
