# SNS に出す動画

X などに出す短い動画を作る道具。撮れるのは 2 種類：カード 1 枚を傾けて光らせる動画と、本物の盤面・開封の画面で演出を見せる場面。10月30日、オーナーが X のアカウントを作り「バズるまで地道に、視覚重視で投稿していく」ことにしたので作った（[history.md](history.md)「10月30日：SNS に出すカードの動画を作る道具」「11月1日：自己紹介の動画を作る」）。

## カードの動画の撮り方

```sh
pnpm dev                       # web を立ち上げておく（撮影用のページを開くため）
pnpm promo:video c17 8.1       # 『演出家』を 8.1 秒撮る → sns/c17.mp4
pnpm promo:video c15           # 秒数を省くと 8 秒
pnpm promo:video c1 8 dark     # 闇堕ちの姿で撮る → sns/c1-dark.mp4
```

- 書き出しは縦長 4:5（1080×1350）・60fps の mp4（H.264）。X のタイムラインで大きく出る形
- 傾きは正面から始まって正面で終わる 8 の字。X で繰り返し再生されても、つなぎ目が出ない
- 書き出し先の `sns/` は git に入れない
- 撮るのは手元の Chrome（Playwright の `channel: "chrome"`）。ffmpeg は初めて撮るときに取りに行く（CI・Docker では落とさない）
- 1 秒分を撮るのに 30〜40 秒ほどかかる。いくつかを同時に撮ると、メモリの少ない Mac では撮影が時間切れになることがある。撮る前に Docker を閉じると、2GB ほど空く（`pnpm verify` のときだけ開く）

## 場面の撮り方

```sh
pnpm dev                       # web を立ち上げておく
pnpm promo:video scene god     # ネ申の降臨を撮る → sns/scene-god.mp4
pnpm promo:video scene win 6   # 秒数を変えるときは後ろに付ける
```

- 書き出しはスマホの縦の形 9:16（1080×1920）・60fps の mp4（H.264）
- 場面は `god`（ネ申）・`arbiter`（『調停者』）・`director`（『演出家』）・`fixer`（『フィクサー』）・`win`（勝ち）・`gacha`（ガチャの開封）
- 盤面・手札・パックの中身は `apps/web/src/promo/scenes.tsx` の `BOARDS`・`PACK`、操作の時刻は `tools/promo-video.mjs` の `SCENES` で決める
- 撮った場面ごとに、鳴らした音の記録 `sns/scene-god.sounds.json` もできる
- 手札を出す・攻撃する・パックを裂くは、指でなぞるのと同じマウスの操作で行う。ルールは本物の `applyAction` を通る。盤面は CPU 対戦の形にしてあるので、相手の番には入らず、演出だけを撮る

## 仕組み

- 撮影用のページ `apps/web/promo.html`（`src/promo/`）が、`?card=ID` のカードを 1 枚だけ濃い青の地の真ん中に出すか、`?scene=名前` の場面を本物の `Board`・`Opening` で出す。本番のビルドには入らない
- 1 コマずつ止めて撮り、つないで動画にする。1 コマ撮るのに時間がかかっても、カード面の動きが先へ進まないよう、ページの時計を止めてから 1 コマ分ずつ進める
  - JS で時間を測って動くもの（『演出家』『フィクサー』の境目など。`performance.now`・`requestAnimationFrame`）は、Playwright の時計（`page.clock`）で止めて進める
  - CSS の動き（ミナモの泡・『調停者』の一太刀など）は、Web Animations の `currentTime` で同じ幅だけ進める
  - カードが出た瞬間から撮るので、出たときの動き（降りてくる・滲む・合わさる）から一連で映る
  - 止めて進めた動きは、終わりに届いても `finish` の合図が来ないことがある。そのままだと `.finished` を待つ演出が先へ進まず、ダメージの数字も消えない。道具の側で終わらせて `onfinish` を呼ぶ
  - 場面は、演出の舞台（PixiJS）・絵・書体・効果音を用意するあいだ時計を流して待ってから止める
- 音はコマ送りでは録れないので、本物は鳴らさず、ページの Web Audio を横取りして、どのコマで・どの音を・どの大きさで鳴らしたかを書き留める。あとから ffmpeg で同じ瞬間に重ねるので、ゲームと同じタイミング・同じ大きさになる。効果音の間隔の判定がずれないよう、音の時計もページの時計に合わせてある
- 秒数は、カード面の動きの一周に合わせる。『演出家』は出てから一周して降り直すまでが 8.1 秒（`directorMotion.ts` の筋書き：降りる 1.5 秒 ＋ 繰り返しの 6.6 秒）

## 撮ったもの

| カード | 秒数 | 映っている動き |
|---|---|---|
| ミナモ（c3） | 8 | 泡が上がりながら傾いて光る |
| 『調停者』（c16） | 8 | ずれた上下が合わさり、一太刀の光と破片が消える |
| 『フィクサー』（c15） | 8 | 白い地に、ふちから黒が滲んで全面が黒になる |
| 『演出家』（c17） | 8.1 | 斜線が降りて止まる → 降り切って全面が赤 → 幕が光の筋に閉じて黒 → また降りる |

## 自己紹介の動画

固定ポスト向けの 37 秒の動画（`sns/intro.mp4`。1080×1920・60fps）。文字は入れない。6 場面を撮ってから、次でつなぐ。

```sh
pnpm promo:video intro               # 全部つないで sns/intro.mp4
pnpm promo:video intro god arbiter   # 撮れた場面だけ試し書き → sns/intro-part.mp4
```

- カットは `tools/promo-video.mjs` の `INTRO`。頭に 0.25 秒・終わりに 0.6 秒のフェードを付ける
- 効果音は記録したとおりに重ねる。カットの終わりに鳴っている音は 0.3 秒で消す
- 対戦の曲（`apps/web/src/sound/battle.mp3`）を切らずに敷く。効果音との比はゲームと同じで、全体だけ 4dB 上げる
- ガチャの開封には効果音がまだないので、その間は曲だけ（11月1日時点）

| 順 | 場面 | 使った範囲（秒） | 映っている動き |
|---|---|---|---|
| 1 | `god` | 0.3〜6.7 | ネ申を出す → 光の柱で降臨 → 神から 3 枚が手札へ飛ぶ |
| 2 | `arbiter` | 0.3〜4.3 | 青い場 → 光線 → 攻撃力がいちばん高い相手の 2 体を破壊 |
| 3 | `gacha` | 0.25〜9.8 | パックを裂く → 4 枚をすばやくめくる → ★5 ミナモが画面いっぱい |
| 4 | `director` | 0.3〜6.9 | 場が赤くなる → 両方のエースが舞台へ → 幕が光の筋に閉じる |
| 5 | `fixer` | 0.3〜5.8 | 場が黒に滲む → 自分と相手が 1 体ずつ差し出して破壊 |
| 6 | `win` | 0.3〜6.0 | 相手のプレイヤーを攻撃 → ライフの帯が砕ける → 「勝利！」 |
