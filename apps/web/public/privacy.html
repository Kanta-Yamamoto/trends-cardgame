TRENDS プライバシーポリシー

TRENDS（以下「本アプリ」）で扱う情報について説明します。

集める情報

  • プレイヤー名（ランキングと対戦の相手の画面に出ます）
  • 端末ごとに本アプリが作る識別子（ログインの代わりに使います。お名前やメールアドレスは含みません）
  • 持っているカード、組んだデッキ、対戦の結果、レーティング
  • CPU 対戦の内容（CPU とカードの調整に使います）
  • App Store の購入の取引 ID（買い切りの確認と、購入の復元に使います。カード番号などの支払い情報は受け取りません）
  • 接続元の IP アドレス（不正な大量アクセスを防ぐために一時的に使います）

使う目的

対戦・ランキング・買い切りの機能を動かすこと、不具合の調査、ゲームの調整のために使います。広告には使いません。

第三者への提供

法律に基づく場合を除き、第三者に提供しません。データの保管には、クラウドサービス（Google Cloud と Neon）を使います。

データを消す

アプリのマイページの「データを消す」で、カード・デッキ・戦績・購入の記録を消せます。プレイヤー名も消え、ランキングに出なくなります。
